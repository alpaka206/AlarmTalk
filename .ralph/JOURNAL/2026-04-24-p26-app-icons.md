# P26 — 앱 아이콘 설정 (adaptive icon + monochrome)

## 선택 근거
BACKLOG 전체 완료 (R0~R6 + P11~P25). 자가 생성 풀에서 "앱 아이콘 설정" 선택.
기존 아이콘이 Expo 기본 플레이스홀더(동심원 패턴)여서 실 서비스 수준에 못 미침.

## 접근
- `sharp` (miniflare 전이 의존성으로 이미 설치됨) + SVG → PNG 변환 방식
- `scripts/generate-icons.mjs` 작성: SVG 문자열을 sharp로 렌더링
- 디자인: 나무 실루엣 (캐릭터 시스템의 나무 테마와 일치)
  - 코랄 그라데이션 배경 (#FF9580 → #FF6B55) + 흰색 나무
  - Rounded square (iOS 스타일)

## 생성된 아이콘
| 파일 | 크기 | 용도 |
|------|------|------|
| icon.png | 1024×1024 | iOS App Store + 일반 아이콘 |
| adaptive-icon.png | 1024×1024 | Android 적응형 아이콘 전경 (흰색 나무, 투명 배경) |
| monochrome-icon.png | 1024×1024 | Android 13+ Material You 테마 아이콘 (검정 실루엣) |
| splash-icon.png | 200×200 | 스플래시 화면 아이콘 |
| favicon.png | 48×48 | 웹 파비콘 |

## 변경 파일
1. `scripts/generate-icons.mjs` — 신규 (아이콘 생성 스크립트)
2. `apps/mobile/assets/icon.png` — 교체 (Expo 기본 → 나무 아이콘)
3. `apps/mobile/assets/adaptive-icon.png` — 교체
4. `apps/mobile/assets/monochrome-icon.png` — 신규
5. `apps/mobile/assets/splash-icon.png` — 교체
6. `apps/mobile/assets/favicon.png` — 교체
7. `apps/mobile/app.json` — `monochromeImage` 추가

## 검증
- typecheck: backend 0 errors, mobile 0 errors
- 아이콘 시각 검증: icon.png (코랄 배경 + 흰 나무), monochrome (검정 실루엣), favicon (작은 버전) 모두 정상
