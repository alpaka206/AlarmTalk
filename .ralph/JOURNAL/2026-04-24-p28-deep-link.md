# P28: 딥 링크 라우트 핸들링

**날짜**: 2026-04-24
**BACKLOG 항목**: 자가 생성 풀 → 딥 링크 라우트 핸들링 (voicealarm:// scheme)

## 접근

Expo Router는 file-based routing으로 `voicealarm://` 스킴 딥 링크를 자동 지원하지만, 다음 3가지가 누락:
1. **Cold start 초기 URL 처리** — 앱이 딥 링크로 열릴 때 초기 URL 네비게이션
2. **Auth gating** — 인증 필요 라우트에 비로그인 사용자 접근 차단
3. **특수 URL 패턴** — `voicealarm://code/VA-XXXX` 같은 단축 URL → 실제 라우트 매핑

### 대안 검토
- **Expo Router 자동 딥 링크만 의존**: scheme 설정만으로 기본 라우팅은 동작하나, auth gating 불가, 특수 패턴 미지원.
- **커스텀 파서 + `Linking.getInitialURL()` + `addEventListener`**: 세밀한 제어 가능. 이 방식 채택.

## 생성/변경 파일

| 파일 | 변경 |
|------|------|
| `src/lib/deepLink.ts` (신규) | URL 파싱 + 라우트 매핑 유틸 (parseDeepLink, createDeepLink) |
| `app/_layout.tsx` | Linking import + 초기 URL 처리 + 런타임 URL 이벤트 리스너 + auth gating |

| URL | 목적지 | 인증 |
|-----|--------|------|
| `voicealarm://code/VA-XXXX-XXXX-XXXX` | `/code-register?code=VA-XXXX-XXXX-XXXX` | 필수 |
| `voicealarm://alarm/create` | `/alarm/create` | 필수 |
| `voicealarm://alarm/{id}` | `/alarm/edit?id={id}` | 필수 |
| `voicealarm://voice/record` | `/voice/record` | 필수 |
| `voicealarm://voice/upload` | `/voice/upload` | 필수 |
| `voicealarm://voice/{id}` | `/voice/[id]` | 필수 |
| `voicealarm://note/create` | `/note/create` | 필수 |
| `voicealarm://note/{id}` | `/note/[id]` | 필수 |
| `voicealarm://message/{id}` | `/message/[id]` | 필수 |
| `voicealarm://people` | `/people` | 필수 |
| `voicealarm://settings` | `/settings` | 필수 |
| `voicealarm://character` | `/character` | 필수 |
| `voicealarm://library` | `/library` | 필수 |

## 설계 결정

- **Silent fail**: 인증 미완료/온보딩 미완료 시 딥 링크 무시 (토스트 없음). 사용자는 일반 플로우로 진입.
- **`deepLinkHandled` ref**: 초기 URL을 한 번만 처리. stateLoaded 후 실행.
- **런타임 이벤트**: 앱이 이미 열린 상태에서 딥 링크 수신 시 실시간 네비게이션.
- **createDeepLink 유틸**: 초대 코드 공유 등에서 딥 링크 URL 생성용.
