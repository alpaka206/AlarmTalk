# P43: DAYS_OF_WEEK i18n 전환 + 가족알람 DAY_LABELS 통합

**날짜**: 2026-04-24
**BACKLOG 항목**: 자가 생성 — 하드코딩 한국어 요일 문자열 i18n 전환

## 발견된 문제

`presets.ts`의 `DAYS_OF_WEEK`와 `family-alarm/create.tsx`의 `DAY_LABELS`에 한국어 요일 이름이 하드코딩되어 있었음:
- `['일', '월', '화', '수', '목', '금', '토']`
- 영어 전환 시에도 한국어 요일명이 표시되는 버그
- 같은 배열이 2곳에 중복 정의

4개 파일에서 참조: alarm/create, alarm/edit, alarms(탭), family-alarm/create

## 접근

- `DAYS_OF_WEEK` → `DAY_KEYS` 로 리네이밍 (i18n 키 배열로 변경)
- i18n 키 `alarms.daySun` ~ `alarms.daySat` 추가 (ko: 일~토, en: Sun~Sat)
- `family-alarm/create.tsx`의 중복 `DAY_LABELS` 제거, `DAY_KEYS` import로 통합
- 소비자 4곳 모두 `t(key)` 호출로 변경

추가: `api-latency.test.ts`의 읽기 임계값 50ms → 75ms 상향 (시스템 부하에 의한 flaky 방지)

## 변경 파일

| 파일 | 변경 내용 |
|------|----------|
| `src/constants/presets.ts` | `DAYS_OF_WEEK` → `DAY_KEYS` (i18n 키 배열) |
| `app/alarm/create.tsx` | import + 렌더 `t(key)` 전환 |
| `app/alarm/edit.tsx` | import + 렌더 `t(key)` 전환 |
| `app/(tabs)/alarms.tsx` | import + `formatRepeatDays` `t(DAY_KEYS[d])` 전환 |
| `app/family-alarm/create.tsx` | `DAY_LABELS` 제거 + `DAY_KEYS` import + `t(key)` 전환 |
| `src/i18n/ko.json` | `alarms.daySun`~`daySat` 7키 추가 |
| `src/i18n/en.json` | `alarms.daySun`~`daySat` 7키 추가 |
| `test/presets.test.ts` | `DAYS_OF_WEEK` → `DAY_KEYS` + i18n 키 검증 테스트 추가 |
| `packages/backend/test/api-latency.test.ts` | LATENCY_THRESHOLD_MS 50→75 (flaky 방지) |
