5Target

처음 검증할 사용자는명확하다

Waker는 모두에게 같은 알람음을 주는 앱이 아닙니다. 매일 다시 듣고 싶은 목소리가 있는 사람부터 시작합니다.

Persona A

좋아하는 연예인의 목소리로 일어나고 싶은 사람

팬심과 루틴을 연결합니다. 반복되는 기본 알람 대신, 아침마다 기대되는 개인화된 한마디를 제공합니다.

Persona B

손주·자식의 목소리를 듣고 싶은 부모님과 시니어

멀리 떨어져 있어도 익숙한 가족의 목소리로 하루를 시작합니다. 알람이 단순한 도구를 넘어 안부가 됩니다.

First wedge

소리보다 관계가 강한 알람

강제로 깨우는 기능은 나중에 붙일 수 있습니다. 1차 검증은 "이 목소리라면 다시 듣고 싶다"는 감정적 기상 경험입니다.

6Behavior

아침은 반복되고시장은 이미 있다

기상은 매일 반복되는 문제입니다. Waker는 이 반복 순간에 개인 음성과 관계를 결합합니다.

Wake-up behavior

불편해도 일어나게 해주는 앱은 쓴다

Alarmy 학술 연구는 사용자가 성공적으로 일어나기 위해 미션형 불편을 감수한다는 점을 보여줍니다.

출처: MDPI Applied Sciences 2020, 미국 사용자 211,273명·5개월·4,290만 건 사용 데이터.

Waker hypothesis

강제보다 정서가 먼저 통할 수 있다

한국 시장에서 관계형 음성이 미션형 강제 기상보다 더 넓게 받아들여질지는 출시 후 검증합니다. 두 접근은 함께 갈 수 있습니다.

7Competition

기상 앱은 있지만관계형 알람은 비어 있다

Waker는 미션, 수면 분석, OS 기본 알람 사이에서 개인 음성과 공유 경험으로 차별화합니다.

Direct competitors
  • Alarmy미션 기반 강제 기상. 1억+ 다운로드, MAU 700만+, 2025년 매출 460억 원.
  • Sleep Cycle수면 분석과 스마트 알람 중심의 글로벌 수면 앱.
  • Sleep as AndroidAndroid 전용 수면 앱. 풍부한 커스터마이즈와 웨어러블 지원.
  • OS Clock무료 기본 앱. 개인 음성·공유·캐릭터 경험은 제한적입니다.

출처: Delightroom 공식 페이지, flex 공식 블로그 2025, 서울경제·벤처스퀘어 2025, Sleep Cycle IR, Urbandroid 공식, Slant 2026.

Positioning

Alarmy가 미션으로 깨운다면, Waker는 목소리로 깨운다

강제 기상은 기능의 한 축입니다. Waker의 첫 포지션은 "내가 듣고 싶은 목소리"와 "소중한 사람이 남긴 한마디"입니다.

Market proof

유료 기상 카테고리는 이미 검증됐다

Alarmy의 매출과 글로벌 MAU는 알람 앱도 충분히 결제 가능한 반복 사용 카테고리라는 근거가 됩니다.

8SWOT

Waker 관점의현실적인 판단

강점은 알람 신뢰성과 관계형 음성입니다. 리스크는 외부 음성 비용, 초기 음성팩 부족, OS 권한 UX입니다.

Strength / Weakness
StrengthOS-native 알람 신뢰성, 가족/연인 공유 음성, 결정적 TTS 캐싱, Android 실기기 100/100 성공.
WeaknessElevenLabs 비용 의존, 1차 출시 시 음성팩 라이브러리 부족, iOS AlarmKit 검증 후 진입.
Opportunity / Threat
Opportunity1인 가구 증가, 스마트 알람 시장 성장, 검증된 유료 알람 카테고리.
ThreatAlarmy의 음성 기능 추가 가능성, OS 기본 시계 발전, ElevenLabs 가격 정책 변동, Android 정확 알람 권한 UX.
Launch focus

먼저 증명할 것은 "목소리 알람을 계속 쓰는가"

초기 지표는 알람 생성 완료율, 음성 재사용률, 공유 초대율, 실제 알람 후 유지율로 잡는 것이 자연스럽습니다.

이제 실제 알람 흐름을영상으로 확인

핵심 기능과 시장 근거를 본 뒤, 실제 알람 생성과 재생 흐름으로 이어집니다.
