# 사용자 매뉴얼

> [English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

**알람톡** — OS-네이티브 음성 알람 앱 사용 설명서.

## 1. 알람톡가 하는 일

알람톡는 사용자가 고른 목소리(직접 녹음한 음성, 업로드한 클립, 가족·연인이 공유한 음성, AI 클론 음성)로 정해둔 시간에 알람을 울려줍니다.

- 네트워크 없이도 동작합니다. 비행기 모드, 잠금 화면, 절전 모드에서도 울립니다.
- 알림이 아니라 진짜 알람입니다. 화면이 꺼져 있어도 울립니다.

## 2. 설치 전 준비

- Android 8.0 이상.
- 이메일 계정 또는 Google 계정.
- 알림, 정확 알람, 풀스크린 권한.
- 음성 녹음을 한다면 마이크 권한.

## 3. 첫 설정 5분

1. **회원가입**
   - 이메일/비밀번호(8자 이상, 영문·숫자 포함) 또는 Google 계정으로 진행.

2. **권한 수락**
   - 알림 · 정확 알람 · 풀스크린 세 카드를 차례로 허용해 주세요.
   - 세 가지 모두 있어야 잠금 화면에서도 알람이 울립니다.

3. **첫 음성 만들기**
   - 음성 탭 → "+ 새 음성".
   - 마이크 권한 허용 → 녹음 시작.
   - 30초 이내로 한 문장 녹음(예: "잘 잤어? 일어날 시간이야.").
   - 이름(예: "엄마 목소리")을 입력하고 저장.

4. **첫 알람 만들기**
   - 알람 탭 → "+ 새 알람".
   - 시간, 반복 요일 선택.
   - 모드는 "알람 + 음성" 추천: 기본 알람 소리가 먼저 나오고, 종료 버튼을 누르면 음성이 한 번 재생됩니다.
   - 방금 만든 음성을 고르고, 읽을 메시지를 입력.
   - 저장.

5. **연습 울림**
   - 1~2분 뒤로 알람을 설정해 보세요.
   - 잠금 화면, 앱 닫힘 상태, 비행기 모드 세 가지에서 확인하세요.

## 4. 권한이 잘 안 잡힐 때

- **알림**: 설정 → 앱 → 알람톡 → 알림 → "알림 허용".
- **정확 알람**: 설정 → 앱 → 알람톡 → "알람 및 리마인더" → 허용. 메뉴 경로는 제조사마다 조금 다릅니다.
- **풀스크린**: Android 14 이상은 별도 메뉴 — 설정 → 앱 → 알람톡 → "전체 화면 알림 액세스".
- **배터리 최적화 제외**: 삼성 One UI, 샤오미 MIUI 등은 알람톡를 배터리 최적화 예외로 넣어야 안정적으로 울립니다.

계정 탭에서 현재 권한 상태를 확인하고 곧바로 시스템 설정으로 이동할 수 있습니다.

## 5. 가족·커플 연결

### 초대 (Owner)

1. 가족 또는 커플 플랜 구독.
2. 사람들 탭 → 가족 그룹 → "초대 코드 만들기".
3. 6자리 코드 발급. **10분 안에 사용**.
4. 메신저·문자·말로 전달하거나 딥링크 사용.

### 참여 (Member)

1. 알람톡 설치 후 로그인.
2. 계정 → 구독·이용권 → "코드 등록".
3. 6자리 입력 후 확인.
4. 참여 완료. 공유 음성이 알람에서 바로 사용 가능합니다.

### 공유 음성으로 알람 만들기

- 새 알람 → 모드 "음성" → 음원 소스 "음성 프로필" → 공유 음성 탭.
- 메시지 입력 후 저장.

## 6. 사용 팁

- **민폐 주의**: 새벽이나 한밤중 알람 테스트는 피하세요. 이웃에게도 들립니다.
- **잘 못 깨는 경우**: 평일 알람을 5~10분 간격으로 세 개 정도 거는 게 효과적입니다.
- **소리**: 알람 볼륨은 시스템 알람 카테고리를 따릅니다. 설정 → 소리 → 알람 볼륨.
- **진동**: 얕은 잠에는 "기본", 깊은 잠에는 "강하게" 권장.

## 7. 구독·이용권

### 플랜

- **Free**: 음성 프로필 1개, TTS 일 5회.
- **Personal**: 음성 프로필 2개, TTS 일 30회.
- **Couple / Family**: 음성 공유, 2~5명.

### 코드

- `VA-XXXX-XXXX-XXXX` → 이용권: 결제 없이 일정 기간 유료 플랜 활성.
- 6자리 숫자 → 가족 그룹 참여.

### 일시 정지·해지

- 결제는 매달 자동 갱신. 계정 → 구독에서 "일시 정지".
- 다음 결제일까지 구독은 유지되고, 그 시각에 자동으로 무료 플랜으로 다운그레이드됩니다.

## 8. 자주 묻는 질문

### Q. 알람이 한 번 안 울렸어요.
- 99%는 권한 문제입니다. 계정 → 권한 상태부터 확인하세요.
- 권한이 다 있는데도 안 울리면 배터리 최적화 예외 설정과 제조사의 "사용 안 하는 앱 자동 종료" 옵션을 해제해 보세요.
- 그래도 안 된다면 고객 지원으로 문의 주세요.

### Q. 서버가 다운되면 알람이 안 울리나요?
- 아닙니다. 알람톡는 디바이스에서 알람을 스케줄링하므로 서버 장애와 무관하게 울립니다.
- 다만 새 TTS 생성·공유 음성 불러오기는 잠시 안 됩니다.

### Q. 녹음한 목소리가 서버에 올라가나요?
- 네. 음성 클론과 TTS 생성을 위해 비공개 스토리지로 업로드됩니다. 계정을 삭제하면 함께 제거됩니다.
- 가족·연인 그룹 내부에서만 공유되며, 외부 다운로드는 막혀 있습니다.

### Q. 가족이 내 목소리를 이상하게 쓰면 어떻게 하나요?
- 그룹에서 음성 프로필을 삭제할 수 있습니다. 도움이 필요하면 설정 → 고객 지원.

### Q. 기본 알람음이 더 많아지나요?
- v1.0 기준은 단일 패턴입니다. 다음 업데이트에서 옵션이 추가됩니다.

## 9. 새 기기로 옮기기

1. 새 기기에 알람톡 설치 → 같은 계정으로 로그인.
2. 계정 → "지금 동기화".
3. 알람 목록, 음성 프로필, 구독이 복원됩니다.
4. 이전 기기에서 녹음한 로컬 음성은 자동 이전되지 않습니다. 필요하면 새 기기에서 다시 녹음하세요. 공유 음성은 그대로 사용 가능.

## 10. 고객 지원

- 보안 관련 이슈는 `SECURITY.md` 의 경로로 제보해 주세요. 일반 제품 문의는 앱 내 지원 링크를 사용하세요.
- 문의 시 다음 정보를 포함해 주세요:
  - 앱 버전 (계정 → 앱 정보)
  - 디바이스 제조사 / 모델 / Android 버전
  - 문제 발생 시각
  - 재현 절차 (가능하다면)

## 11. 용어 정리

| 용어 | 의미 |
|---|---|
| 음성 프로필 | 녹음·업로드로 만든 클론 음성. |
| TTS | Text-to-Speech. 텍스트를 음성으로 변환. |
| 공유 음성 | 가족·연인 그룹의 다른 멤버가 만든 음성 프로필. |
| 알람 모드 | "알람만", "음성만", "알람 + 음성". |
| 스누즈 | 알람을 잠시 미뤘다가 다시 울리게 함. |
| 초대 코드 | 가족 그룹 참여용 6자리 숫자. 10분 만료, 1회용. |
| 이용권 코드 | 프로모션·제휴로 받는 `VA-XXXX-XXXX-XXXX`. |
| 캐릭터 | 알람을 완료하면 자라는 4단계 캐릭터. |
