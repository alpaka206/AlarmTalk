# 사용자 매뉴얼

> [English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

**알람톡** — OS-네이티브 음성 알람 앱 사용 설명서.

## 1. 알람톡이 하는 일

알람톡은 사용자가 고른 목소리(직접 녹음한 음성, 업로드한 클립, 가족·연인이 공유한 음성, AI 클론 음성)로 정해둔 시간에 알람을 울려줍니다.

- 네트워크 없이도 동작합니다. 비행기 모드, 잠금 화면, 절전 모드에서도 울립니다.
- 알림이 아니라 진짜 알람입니다. 화면이 꺼져 있어도 울립니다.

## 2. 설치 전 준비

- Android 8.0 이상, 또는 iOS 26 이상의 iPhone.
- 이메일 계정, 또는 Google 계정(Android)·Apple 계정(iPhone).
- 권한 — Android: 알림·정확한 알람·전체 화면 알람. iPhone: 알람 권한(없으면 알람이 예약되지 않습니다). 알림 권한은 선택입니다.
- 음성 녹음을 한다면 마이크 권한.

## 3. 첫 설정 5분

1. **회원가입**
   - 이메일/비밀번호(8자 이상, 영문·숫자 포함)로 가입.
   - 또는 로그인 화면의 "Google로 로그인"(Android)·"Apple로 로그인"(iPhone). 처음 로그인하면 계정이 바로 만들어집니다.

2. **권한 수락**
   - **Android**: 알림 권한을 물으면 허용해 주세요. "정확한 알람 권한을 허용해야 알람을 설정할 수 있어요"·"잠금 화면 알람 권한을 허용해야 알람을 설정할 수 있어요" 화면이 뜨면 "허용하기"를 누르고, 열리는 설정 화면에서 켜 주세요. 알림·정확한 알람·전체 화면 알람 셋이 다 있어야 알람을 만들고·고치고·켤 수 있습니다.
   - **iPhone**: 가입을 마치고 앱 화면에 들어오면 알림 권한을 묻습니다 — 가족이 보낸 알람 같은 소식을 알리는 데만 씁니다. 알람 권한은 첫 알람을 만들 때 묻습니다. 꼭 허용해 주세요. 알람 권한이 없으면 알람이 예약되지 않아 울리지 않습니다.

3. **첫 음성 만들기** (유료 플랜)
   - 내 목소리 프로필은 유료 플랜 기능입니다. 무료 플랜은 4단계로 넘어가 기본 제공 목소리를 쓰면 됩니다.
   - 목소리 탭 → "+ 새 음성".
   - 마이크 권한 허용 → 녹음 시작.
   - **12초 이상 2분 이하**로 녹음(예: "잘 잤어? 일어날 시간이야." 같은 문장을 이어서 자연스럽게). 길게 말할수록 목소리가 더 비슷해지지만, 짧아도 등록은 됩니다.
   - 등록하려는 목소리의 오디오 파일이 없다면, **그 사람이 나오는 영상을 틀어 놓고 녹음**해도 됩니다. 영상 파일을 그대로 업로드해도 됩니다.
   - 이름(예: "엄마 목소리")을 입력하고 저장.

4. **첫 알람 만들기**
   - 알람 탭 → "+ 새 알람".
   - 시간, 반복 요일 선택.
   - 모드는 "목소리" 추천: 알람을 끌 때까지 목소리가 반복됩니다. 다른 하나인 "알람"은 기본 알람음만 씁니다.
   - 방금 만든 음성을 고르고, 읽을 메시지를 입력.
   - 저장.

5. **연습 울림**
   - 1~2분 뒤로 알람을 설정해 보세요.
   - 잠금 화면, 앱 닫힘 상태, 비행기 모드 세 가지에서 확인하세요.

## 4. 권한이 잘 안 잡힐 때

**Android**

- **알림**: 설정 → 앱 → 알람톡 → 알림 → "알림 허용".
- **정확 알람**: 설정 → 앱 → 알람톡 → "알람 및 리마인더" → 허용. 메뉴 경로는 제조사마다 조금 다릅니다.
- **풀스크린**: Android 14 이상은 별도 메뉴 — 설정 → 앱 → 알람톡 → "전체 화면 알림 액세스".
- **배터리 최적화 제외**: 삼성 One UI, 샤오미 MIUI 등은 알람톡을 배터리 최적화 예외로 넣어야 안정적으로 울립니다.

권한이 모자라면 알람 탭의 알람 목록 위에 어떤 권한인지 알려 주는 배너가 뜹니다. 누르면 그 권한 설정으로 바로 갑니다.

**iPhone**

- **알람 권한**: 알람이 울릴지를 정하는 유일한 권한입니다. 없으면 알람이 아예 예약되지 않고, 알람 탭의 알람 목록 위에 "알람 권한이 없어 알람이 예약되지 않아요." 배너가 뜹니다.
- 한 번 거부하면 iOS 는 다시 묻지 않습니다. 알람을 만들려고 하면 알람톡이 설정 앱의 알람톡 화면을 열어 주니, 거기서 알람 권한을 다시 켜 주세요.
- **알림**: 선택입니다. 가족이 보낸 알람 같은 소식을 알리는 데만 쓰며, 알림 권한이 없어도 알람은 울립니다.

## 5. 가족·커플 연결

### 초대 (Owner)

1. 가족 또는 커플 플랜 구독.
2. 더보기 탭 → 가족·커플 그룹 → "초대 코드 만들기".
3. `INV-XXXX-XXXX-XXXX` 형식의 초대 코드 발급. 이용권이 유지되는 동안 유효합니다.
4. 메신저·문자·말로 전달.

### 참여 (Member)

1. 알람톡 설치 후 로그인.
2. 더보기 탭 → "코드 등록".
3. 받은 코드를 입력하고 확인.
4. 참여 완료. 공유 음성이 알람에서 바로 사용 가능합니다.

### 공유 음성으로 알람 만들기

- 새 알람 → 모드 "음성" → 음원 소스 "음성 프로필" → 공유 음성 탭.
- 메시지 입력 후 저장.

## 6. 사용 팁

- **민폐 주의**: 새벽이나 한밤중 알람 테스트는 피하세요. 이웃에게도 들립니다.
- **잘 못 깨는 경우**: 평일 알람을 5~10분 간격으로 세 개 정도 거는 게 효과적입니다.
- **소리**
  - Android: 알람마다 목소리·알람음 크기를 편집기에서 따로 정합니다. 울리는 동안에는 기기 알람 볼륨이 낮으면 앱이 올렸다가 끝나면 되돌리므로, 시스템 슬라이더를 내려도 알람이 작아지지는 않습니다.
  - iPhone: 알람마다 편집기의 "목소리 크기"로 정합니다. 알람음은 iOS 가 직접 울리므로 알람음 크기 설정은 없습니다.
- **진동**(Android): 얕은 잠에는 "기본", 깊은 잠에는 "강하게" 권장. iPhone 앱에는 진동 설정이 없습니다.

## 7. 구독·이용권

### 플랜

- **무료**: 기본 제공 목소리 + 프리셋 문구. 내 목소리 프로필과 문구 직접 입력은 잠겨 있습니다.
- **개인**: 내 목소리 프로필 + 문구 직접 입력(월 한도 안에서).
- **커플 / 가족**: 개인 플랜 기능 전부 + 2~5명 음성 공유.

현재 가격과 한도는 앱의 더보기 → 이용권 화면에 표시됩니다.

### 코드

- `INV-XXXX-XXXX-XXXX` → 가족·커플 그룹 합류.
- `GIFT-XXXX-XXXX-XXXX` → 선물받은 개인 이용권 활성.
- 그 밖의 프로모션 코드 → 안내받은 문자열 그대로 입력.

### 해지

- 결제는 매달 자동 갱신. 더보기 → 이용권에서 "이용권 해지". 일시 정지는 없습니다.
- **Google Play 로 결제한 경우** — 끝나는 시점을 고릅니다.
  - **종료일에 해지**: 다음 결제일까지 그대로 쓰고, 그 시각에 자동으로 무료 플랜이 됩니다.
  - **지금 해지**: 남은 기간 요금이 비례 환불되고 이용권이 바로 끝납니다. 목소리는 3일간 보관되며, 그 안에 이용권을 다시 등록하면 그대로 쓸 수 있고 지나면 영구 삭제됩니다.
- **App Store(iPhone)로 결제한 경우**: 해지는 Apple 구독 관리에서 합니다. iPhone 에서 "이용권 해지"를 누르면 그 화면이 열립니다. 해지해도 이미 결제한 기간은 그대로 쓸 수 있고, 앱에서 "지금 해지"(비례 환불)는 할 수 없습니다.

## 8. 자주 묻는 질문

### Q. 알람이 한 번 안 울렸어요.
- **Android**: 권한이 없어도 알람은 울립니다. 대신 알림 권한이 없으면 알람 알림이 뜨지 않고, 정확한 알람 권한이 없으면 제때 울리지 않을 수 있으며, 잠금 화면 권한이 없으면 잠금 화면에 뜨지 않습니다. 무엇이 모자란지는 알람 탭 배너가 알려 줍니다. 정말 소리가 나지 않았다면 배터리 최적화 예외 설정과 제조사의 "사용 안 하는 앱 자동 종료" 옵션을 해제해 보세요.
- **iPhone**: 알람 권한이 없으면 알람이 예약되지 않아 정말로 울리지 않습니다. 알람 탭에 "알람 권한이 없어 알람이 예약되지 않아요." 배너가 보이면 권한을 다시 켜 주세요(4번 항목 참고).
- 그래도 안 된다면 고객 지원으로 문의 주세요.

### Q. 서버가 다운되면 알람이 안 울리나요?
- 아닙니다. 알람톡은 디바이스에서 알람을 스케줄링하므로 서버 장애와 무관하게 울립니다.
- 다만 새 TTS 생성·공유 음성 불러오기는 잠시 안 됩니다.

### Q. 녹음한 목소리가 서버에 올라가나요?
- 네. 음성 클론과 TTS 생성을 위해 비공개 스토리지로 업로드됩니다. 계정을 삭제하면 함께 제거됩니다.
- 가족·연인 그룹 내부에서만 공유되며, 외부 다운로드는 막혀 있습니다.

### Q. 가족이 내 목소리를 이상하게 쓰면 어떻게 하나요?
- 그룹에서 음성 프로필을 삭제할 수 있습니다. 도움이 필요하면 설정 → 고객 지원.

### Q. 알람음을 바꿀 수 있나요?
- 네. 모드를 "알람"으로 두고 편집기의 "알람음" 항목에서 기기에 있는 알람음 중 하나를 고르면 됩니다.

## 9. 새 기기로 옮기기

1. 새 기기에 알람톡 설치 → 같은 계정으로 로그인.
2. 로그인하면 알람 목록, 음성 프로필, 구독이 복원됩니다.
3. 이전 기기에서 녹음한 로컬 음성은 자동 이전되지 않습니다. 필요하면 새 기기에서 다시 녹음하세요. 공유 음성은 그대로 사용 가능.

## 10. 고객 지원

- 보안 관련 이슈는 `SECURITY.md` 의 경로로 제보해 주세요. 일반 제품 문의는 앱 내 지원 링크를 사용하세요.
- 문의 시 다음 정보를 포함해 주세요:
  - 앱 버전 (더보기 탭 맨 아래)
  - 디바이스 제조사 / 모델 / Android·iOS 버전
  - 문제 발생 시각
  - 재현 절차 (가능하다면)

## 11. 용어 정리

| 용어 | 의미 |
|---|---|
| 음성 프로필 | 녹음·업로드로 만든 클론 음성. |
| TTS | Text-to-Speech. 텍스트를 음성으로 변환. |
| 공유 음성 | 가족·연인 그룹의 다른 멤버가 만든 음성 프로필. |
| 알람 모드 | "알람"(기본 알람음) 또는 "목소리"(고른 목소리, 반복). |
| 스누즈 | 알람을 잠시 미뤘다가 다시 울리게 함. |
| 초대 코드 | 가족·커플 그룹 합류용 `INV-XXXX-XXXX-XXXX`. |
| 선물 코드 | 개인 이용권 선물용 `GIFT-XXXX-XXXX-XXXX`. |
