# ユーザーマニュアル

> [English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

**AlarmTalk** — OS ネイティブの音声アラームアプリのユーザー向け説明書。

## 1. AlarmTalk でできること

AlarmTalk は、ユーザーが選んだ声(自分の録音、アップロードしたクリップ、家族や恋人と共有した音声、AI クローンの音声)で、指定した時刻にアラームを鳴らします。

- ネットワーク不要で動作。機内モード、ロック画面、省電力モードでも鳴ります。
- 通知ではなく本物のアラーム。画面が消えていても鳴ります。

## 2. インストール前に

- Android 8.0 以降、または iOS 26 以降の iPhone。
- メールアカウント、または Google アカウント(Android)・Apple アカウント(iPhone)。
- 権限 — Android:通知・正確なアラーム・全画面アラーム。iPhone:アラームの権限(ないとアラームが予約されません)。通知の権限は任意です。
- 自分の声を録音する場合はマイク権限。

## 3. 最初の 5 分

1. **アカウント作成**
   - メール/パスワード(8 文字以上、英字と数字を含む)で登録。
   - または、ログイン画面の「Googleでログイン」(Android)・「Appleでサインイン」(iPhone)。初回のログインでアカウントが作成されます。

2. **権限を許可**
   - **Android**:通知の権限を求められたら許可してください。「正確なアラームの権限を許可するとアラームを設定できます」「ロック画面の権限を許可するとアラームを設定できます」が表示されたら「許可する」をタップし、開いた設定画面でオンにしてください。通知・正確なアラーム・全画面アラームの 3 つがそろって初めて、アラームの作成・編集・オンができます。
   - **iPhone**:登録を終えてアプリの画面に入ると、通知の権限を求められます — 家族から届いたアラームなどのお知らせにだけ使います。アラームの権限は最初のアラームを作成するときに求められます。必ず許可してください。アラームの権限がないとアラームが予約されず、鳴りません。

3. **最初の音声を作る**(有料プラン)
   - 自分のボイスプロフィールは有料プラン向けの機能です。無料プランは手順 4 に進み、標準搭載の音声を使ってください。
   - 音声タブ → 「+ 新しい音声」。
   - マイク権限を許可 → 録音開始。
   - **12 秒以上 2 分以内**で録音(例:「おはよう、起きる時間だよ」のように自然に話し続ける)。長く話すほど似ますが、短くても登録できます。
   - 登録したい声の音声ファイルがなければ、**その人が映っている動画を再生して録音**してもかまいません。動画ファイルをそのままアップロードしても大丈夫です。
   - 名前(例:「ママの声」)を入力して保存。

4. **最初のアラームを作る**
   - アラームタブ → 「+ 新しいアラーム」。
   - 時刻と繰り返し曜日を選択。
   - モードは「音声」がおすすめ:アラームを止めるまで音声が繰り返されます。もう一方の「アラーム」は標準音のみです。
   - 先ほど作成した音声を選び、読み上げメッセージを入力。
   - 保存。

5. **テスト鳴動**
   - 1~2 分後にアラームを設定して試してください。
   - ロック画面、アプリを閉じた状態、機内モードの 3 つで確認しましょう。

## 4. 権限がうまく設定できないとき

**Android**

- **通知**: 設定 → アプリ → AlarmTalk → 通知 → 「通知を許可」。
- **正確なアラーム**: 設定 → アプリ → AlarmTalk → 「アラームとリマインダー」 → 有効化。メーカーによってメニュー位置が少し異なります。
- **全画面通知**: Android 14 以降では専用メニューがあります — 設定 → アプリ → AlarmTalk → 「全画面通知へのアクセス」。
- **電池の最適化を除外**: Samsung One UI、Xiaomi MIUI など一部メーカーでは、AlarmTalk を電池最適化の例外にする必要があります。

権限が足りないときは、アラームタブのリスト上部にどの権限かを示すバナーが表示されます。タップするとその設定画面へ直接移動します。

**iPhone**

- **アラームの権限**:アラームが鳴るかどうかを決める唯一の権限です。ないとアラームがまったく予約されず、アラームタブのリスト上部に「アラームの権限がないため、アラームが予約されません。」というバナーが表示されます。
- 一度拒否すると iOS は再び尋ねません。アラームを作成しようとすると AlarmTalk が設定アプリの AlarmTalk の画面を開くので、そこでアラームの権限をオンに戻してください。
- **通知**:任意です。家族から届いたアラームなどのお知らせにだけ使い、通知の権限がなくてもアラームは鳴ります。

## 5. 家族やパートナーとつなぐ

### 招待する(オーナー)

1. ファミリーまたはカップルプランに加入。
2. 「その他」タブ → ファミリー/カップルグループ → 「招待コードを作成」。
3. `INV-XXXX-XXXX-XXXX` 形式の招待コードが発行されます。プランが有効な間は使えます。
4. メッセンジャー、SMS、口頭で共有。

### 参加する(メンバー)

1. AlarmTalk をインストールしてサインイン。
2. 「その他」タブ → 「コードを登録」。
3. 受け取ったコードを入力して確認。
4. 参加完了。共有音声が任意のアラームで使えるようになります。

### 共有音声でアラームを作る

- 新規アラーム → モード「音声」 → 音声ソース「ボイスプロフィール」 → 共有音声タブ。
- メッセージを入力して保存。

## 6. 使いこなしのコツ

- **配慮**:深夜や早朝のテスト鳴動は避けてください。近所にも届きます。
- **深い眠り**:平日アラームを 5~10 分間隔で 3 つ並べると効果的です。
- **音量**
  - Android:音声・アラーム音の大きさはアラームごとに編集画面で設定します。鳴動中は端末のアラーム音量が低ければアプリが一時的に上げ、終了後に元へ戻すため、システムのスライダーを下げてもアラームは小さくなりません。
  - iPhone:アラームごとに編集画面の「声の大きさ」で設定します。アラーム音は iOS が直接鳴らすため、アラーム音の音量設定はありません。
- **バイブレーション**(Android):浅い眠りは「ベーシック」、深い眠りは「強め」がおすすめ。iPhone のアプリにはバイブレーションの設定はありません。

## 7. サブスクリプションとコード

### プラン

- **無料**:標準搭載の音声とプリセット文のみ。自分のボイスプロフィールと文章の自由入力はロックされています。
- **個人**:自分のボイスプロフィールと文章の自由入力(月間上限の範囲内)。
- **カップル / ファミリー**:個人プランの機能すべてに加えて、2~5 人での音声共有。

現在の価格と上限はアプリの「その他」→「利用券」画面に表示されます。

### コード

- `INV-XXXX-XXXX-XXXX` → ファミリー・カップルグループに参加。
- `GIFT-XXXX-XXXX-XXXX` → 贈られた個人プランを有効化。
- その他のプロモーションコード → 案内された文字列をそのまま入力。

### 解約

- 支払いは毎月自動更新。「その他」→「利用券」で「利用券を解約」。一時停止はありません。
- **Google Play で支払った場合** — 終了のタイミングを選べます。
  - **終了日に解約**:次回請求日まではそのまま使え、その時点で自動的に Free になります。
  - **今すぐ解約**:残り期間分が日割りで返金され、プランは即時終了します。音声は 3 日間保管され、その間にプランを再登録すればそのまま使えます。過ぎると完全に削除されます。
- **App Store(iPhone)で支払った場合**:解約は Apple のサブスクリプション管理で行います。iPhone で「利用券を解約」をタップするとその画面が開きます。解約しても支払い済みの期間はそのまま使え、アプリでの「今すぐ解約」(日割り返金)はできません。

## 8. よくある質問

### Q. アラームが 1 回鳴らなかった。
- **Android**:権限がなくてもアラームは鳴ります。通知権限がないと通知が表示されず、正確なアラーム権限がないと数分遅れることがあり、全画面権限がないとロック画面に表示されません。何が足りないかはアラームタブのバナーが知らせます。本当に音が出なかった場合は、電池最適化の除外と、メーカーの「未使用アプリの自動停止」設定を解除してください。
- **iPhone**:アラームの権限がないとアラームが予約されないため、本当に鳴りません。アラームタブに「アラームの権限がないため、アラームが予約されません。」と表示されたら、権限をオンに戻してください(「4. 権限がうまく設定できないとき」参照)。
- それでも改善しない場合はサポートまで連絡してください。

### Q. サーバーが落ちたらアラームは鳴らない?
- 鳴ります。AlarmTalk はデバイス内部でアラームをスケジュールするため、サーバー障害の影響を受けません。
- 新しい TTS 生成や共有音声の取得は一時的に停止します。

### Q. 録音した声はサーバーにアップロードされる?
- はい。音声クローンと TTS 生成のために、非公開のクラウドストレージへアップロードされます。アカウントを削除すると一緒に削除されます。
- ファミリー/パートナーグループ内でのみ共有され、外部ダウンロードは設計上ブロックされます。

### Q. 家族が私の声を望まない使い方をしたら?
- グループから自分のボイスプロフィールを削除できます。サポートが必要なら設定 → サポート。

### Q. アラーム音は変えられる?
- はい。モードを「アラーム」にして、編集画面の「アラーム音」から端末にあるアラーム音を選べます。

## 9. 新しい端末への移行

1. 新しい端末に AlarmTalk をインストールし、同じアカウントでサインイン。
2. サインインするとアラーム一覧、ボイスプロフィール、サブスクリプションが復元されます。
3. 古い端末でローカル録音した音声は自動移行されません。必要に応じて新しい端末で録音し直してください。共有音声はそのまま利用できます。

## 10. サポート

- セキュリティ関連は `SECURITY.md` のチャネルで報告してください。一般的な製品サポートはアプリ内のサポートリンクを使ってください。
- 問い合わせには以下を含めてください:
  - アプリのバージョン(「その他」タブの最下部)
  - 端末メーカー / 機種 / Android・iOS バージョン
  - 発生時刻
  - 可能なら再現手順

## 11. 用語集

| 用語 | 意味 |
|---|---|
| ボイスプロフィール | 録音やアップロードから作成したクローン音声。 |
| TTS | Text-to-Speech。テキストを音声に変換。 |
| 共有音声 | ファミリー/パートナーグループの他メンバーが作った音声プロフィール。 |
| アラームモード | 「アラーム」(標準音)または「音声」(選んだ声、繰り返し)。 |
| スヌーズ | アラームを少し延ばしてもう一度鳴らす。 |
| 招待コード | ファミリー・カップルグループ参加用の `INV-XXXX-XXXX-XXXX`。 |
| ギフトコード | 贈られた個人プラン用の `GIFT-XXXX-XXXX-XXXX`。 |
