# VoiceAlarm — 프로젝트 개요

## 1. 서비스 소개

**VoiceAlarm**은 소중한 사람의 목소리로 하루를 시작할 수 있는 알람 앱입니다.

사용자가 음성을 등록하면 AI 음성 클론 기술(TTS)로 다양한 메시지를 생성하여 알람으로 재생합니다. 가족/커플 플랜을 통해 서로에게 알람과 음성 쪽지를 보낼 수 있습니다.

### 핵심 가치
- **따뜻함**: 기계음 대신 사랑하는 사람의 목소리로 기상
- **연결**: 가족/커플 간 음성 메시지와 알람 공유
- **동기부여**: 나무 캐릭터 성장 + 연속 기상 스트릭으로 습관 형성

### 타겟 유저
- 커플: 서로의 목소리로 알람/쪽지 교환
- 가족: 부모↔자녀, 형제 간 음성 알람 전송
- 개인: 본인 음성 또는 프리셋 음성으로 맞춤 알람

### 지원 플랫폼
- 모바일: iOS / Android (React Native + Expo)
- 백엔드: Cloudflare Workers (글로벌 엣지 배포)

## 2. 주요 기능 정의

### 2-1. 음성 관리
| 항목 | 설명 |
|------|------|
| 음성 프로필 | 사용자당 최대 2개 등록 가능 |
| 등록 방법 | 직접 녹음 / 오디오 파일 업로드 |
| 화자 분리 | 업로드 파일에서 특정 화자 추출 (Diarization) |
| 음성 클론 | Perso.ai API로 음성 복제 → TTS 변환 |
| 가족 음성 | 같은 그룹 멤버의 음성 열람 (읽기 전용) |

### 2-2. 알람
| 항목 | 설명 |
|------|------|
| 기본 알람 | 시간 + 반복 요일 + 라벨 설정 |
| 깨우기 방식 | `sound_then_voice` (소리 → 음성) / `voice_only` |
| 음성 선택 | 내 음성 / 가족 음성 / 프리셋 음성 |
| 진동 패턴 | 기본 / 강하게 / 없음 |
| 스누즈 | 알림 액션 버튼으로 스누즈/끄기 |
| 오프라인 | 음성 파일 로컬 캐싱으로 네트워크 없이도 재생 |

### 2-3. 메시지 & 쪽지
| 항목 | 설명 |
|------|------|
| 메시지 작성 | 텍스트 입력 → TTS 음성 생성 → 라이브러리 저장 |
| 쪽지 보내기 | 가족 멤버에게 텍스트 쪽지 전송 (비동기, 푸시 알림) |
| 가족 알람 | 가족 멤버에게 알람 예약 (시간 + 메시지 + 반복) |
| 라이브러리 | 수신 메시지 보관함 (즐겨찾기, 카테고리 필터) |
| 프리셋 메시지 | 카테고리별 기본 제공 메시지 (매일 랜덤 재생 가능) |

### 2-4. 캐릭터 시스템 (나무 테마)
| 항목 | 설명 |
|------|------|
| 성장 단계 | 🌰 씨앗 → 🌱 새싹 → 🌳 나무 → 🌸 꽃 |
| 경험치(XP) | 알람 해제, 메시지 청취 등 활동으로 획득 |
| 연속 기상 | 🔥 스트릭 카운트 + 마일스톤 보상 (7/30/90일) |
| 능력치 | 뿌리 깊이(diligence) / 줄기 튼튼함(health) / 잎 무성함(consistency) |

### 2-5. 소셜 & 플랜
| 항목 | 설명 |
|------|------|
| 친구 | 이메일로 친구 추가/삭제, 요청 수락 |
| 가족 그룹 | 초대 코드로 그룹 가입 (owner가 코드 발급) |
| 플랜 | free / personal / family (결제 스텁 구현) |
| 코드 등록 | 이용권 코드(VA-XXXX-XXXX-XXXX) 또는 가족 초대 코드(6자리) 입력 |
| 선물 | 친구에게 음성 메시지 선물 (수락/거부) |

### 2-6. 설정
| 항목 | 설명 |
|------|------|
| 프로필 | 이름, 이메일, 플랜 정보 |
| 다크모드 | 전체 화면 다크 테마 지원 |
| 언어 | 한국어 / 영어 전환 |
| 푸시 알림 | FCM 토큰 자동 등록 |
| 앱 정보 | 버전, 라이선스, 개인정보처리방침, 문의하기 |

## 4. 사용자 시나리오

### 시나리오 1: 신규 가입 → 음성 등록 → 알람 설정

1. 앱 설치 후 첫 실행 → 온보딩 4페이지 (나무 성장 스토리)
2. 이메일/비밀번호 또는 Google 로그인
3. 캐릭터 자동 생성 (🌰 씨앗 단계)
4. **음성 탭** → "음성 추가" → 녹음 또는 파일 업로드
5. 음성 클론 처리 (Perso.ai) → 프로필 생성
6. **알람 탭** → "+" → 시간/요일 설정
7. 깨우기 방식: "소리 후 음성" 선택 → 음성 프로필 지정
8. 메시지 입력 또는 프리셋 카테고리 선택
9. 알람 저장 → 다음 날 아침 알람 → 음성 재생

### 시나리오 2: 커플 플랜 → 서로 알람 보내기

1. A가 가족 플랜 가입 (코드 등록 또는 직접 구매)
2. A가 **프로필 > 내 사람들 > 멤버** → 초대 코드 발급
3. B가 코드를 받아 **프로필 > 코드 등록** → 6자리 입력 → 그룹 가입
4. B가 음성 프로필 등록
5. A의 **메시지 탭** → "알람 보내기" → B 선택 → 시간/메시지 설정
6. 설정 시간에 B 기기에서 알람 + A의 음성 재생
7. B도 동일하게 A에게 알람 전송 가능

### 시나리오 3: 가족 그룹 → 쪽지 교환

1. 가족 그룹 설정 완료 (시나리오 2와 유사)
2. A가 **메시지 탭** → "쪽지 보내기" → B 선택
3. 텍스트 입력 (500자 제한) → 전송
4. B에게 푸시 알림 도착
5. B가 **메시지 탭** → "받은 쪽지" → 텍스트 확인 (읽음 처리)

### 시나리오 4: 연속 기상 스트릭 → 캐릭터 성장

1. 매일 아침 알람 해제 → XP 획득
2. **홈 탭** 캐릭터 위젯에서 🔥 스트릭 카운트 확인
3. 7일 연속 → 마일스톤 배지 + 보너스 XP
4. XP 누적 → 🌰→🌱→🌳→🌸 단계 진화
5. **캐릭터 화면**에서 능력치 바 + 달성 기록 확인
6. 30일/90일 마일스톤 → 추가 보상

### 시나리오 5: 오프라인 사용

1. 음성 프로필이 등록되면 오디오 파일 로컬 캐싱
2. 알람/메시지 데이터도 AsyncStorage에 캐싱
3. 네트워크 없는 환경에서도 알람 정상 울림 + 캐싱된 음성 재생
4. 오프라인 배너 표시 → 네트워크 복구 시 자동 동기화
