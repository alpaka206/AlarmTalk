## 직접 연결된 경로와 한계

- 등급 선택은 조회 순서 자체를 바꾸지 않고 권한 재계산 두 경로에서 같은 선택 함수를 쓴다.
  구독·그룹·결제 원장을 새로 만들거나 지우지 않으며 제외된 보류 구독은 선택하지 않는다.
- offset 호환은 서버 쓰기나 마이그레이션 실패의 폴백이 아니다. 커서로 시작한 회차가
  중간에 구형 응답을 받으면 실패한다. 신서버의 커서·전달 세대 검증은 유지한다.
  구형 offset은 다른 기기의 동시 삭제·재정렬에서 누락을 완전히 막지는 못한다.
- 전송 대기는 앞 호출이 끝나야 진행한다. 무제한 분리 작업을 만들거나 BGTask 취소를 무시하지 않는다.
- 실기기의 가족 푸시 도착·예약과 실제 BGTask 만료 검증은 릴리스 단계에 남는다.

## #739 후속 — 보류 구독 제외·구서버 수신 표시

`ecd8c3b2`에 새로 달린 [보류 구독 P2](https://github.com/alpaka206/AlarmTalk/pull/739#discussion_r4000092564)와
[구형 수신 표시 P1](https://github.com/alpaka206/AlarmTalk/pull/739#discussion_r4000092566)을 수정했다.

- 앞선 등급 선택은 active 행 중 높은 등급을 골랐지만, 보류 행도 복구를 위해 active로
  남아 있어 다른 구독 해지 때 공유 권한이 되살아났다. `entitlement_state`를 저장해
  보류·미확인 행은 재계산에서 계속 제외한다. 남은 근거가 보류뿐인 경우의 free 전환은
  공유 구조·데이터를 영구 정리하지 않는다. 정상 복구는 해당 구독·그룹만 entitled로 되돌린다.
- 마이그레이션 118을 추가했다. 과거에는 보류 상태를 저장하지 않아 추측으로 백필할 수 없다.
  기존 스토어 연결 활성 구독·그룹 멤버는 unverified로 두고 다음 스토어 정합화로 확정한다.
  현재 users.plan은 마이그레이션에서 바꾸지 않는다. 다만 재확인 전 다른 구독을 해지하면
  미확인 행으로 유료 권한을 새로 부여하지 않으므로 일시적으로 free로 표시될 수 있다.
  기존 마이그레이션·지문은 그대로이며 118의 지문만 추가했다. DB 적용·배포는 하지 않았다.
- Android는 현대/구형 수신 표시를 별도 nullable 필드로 읽고 현대 값을 우선한다.
  두 필드를 OR하거나 Gson 대체 이름으로 합치지 않아 명시적인 현대 false를 보존한다.
  기존 2,601건 HTTP 회귀의 구서버 응답도 실제 `is_received_family_alarm`로 바로잡고
  실제 pull과 같은 필터를 통과한 수신 목록을 확인하도록 했다.
- 회귀 사례: Apple retry·Play ON_HOLD 후 소유자/멤버의 독립 구독 해지와 재계산·복구,
  보류 쓰기 실패의 원자적 롤백, 기존 DB의 마이그레이션 대상·재실행 보존,
  두 수신 필드의 누락·충돌·JSON 순서. 작성만 했고 로컬 빌드·테스트는 실행하지 않았다.

## #739 CI 실패 수정 — 테스트 헬퍼 범위·과거 프로모 스키마

`0282a42f`의 [원격 백엔드 테스트](https://github.com/alpaka206/AlarmTalk/actions/runs/34768272950/job/103753071107)는
4건 실패·1,823건 통과·64건 건너뜀으로 끝났다. 실패 원인은 다음 두 가지다.

- 새 Google 보류·복구 사례가 다른 `describe` 안의 `playState`를 호출해
  `ReferenceError`가 났다. 같은 모의 응답 함수를 파일 공용 범위로 옮겼다.
- 과거 프로모 마이그레이션 #71·#72·#77에서 멈춘 테스트 DB 세 곳은 현행 결제 코드가
  조회하는 `entitlement_state`가 없어 실패했다. 해당 프로모 상태를 유지하며 테스트 DB에
  실제 #118만 추가 적용하도록 했다. 프로모 그룹 컬럼 누락 폴백의 검증 범위도 명시했다.

프로덕션 조회·마이그레이션과 기존 테스트 단언은 변경하지 않았다. 로컬 빌드·테스트는
실행하지 않았고 수정 후 원격 CI 완료도 기다리지 않는다. 위 수치는 수정 전 결과다.
