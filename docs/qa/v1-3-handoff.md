## 2. 출시 순서 (develop → main, 오너가 실행)

순서를 바꾸지 않는다. 근거는 각 스펙과 `CLAUDE.md` 「배포 / 환경」.

1. **창을 피한다** — 2026-10-31 15:00Z ~ 11-04(기간 한정 개인 플랜 종료와 목소리 정리,
   [`personal-promo-end-runbook.md`](../ops/personal-promo-end-runbook.md)). 그 작업이 이번에 바뀐 권한·보관 코드를 지난다.
2. **dev 에서 마이그레이션 확인** — develop 머지마다 dev 가 이미 돌렸다. main 은 #134~#144 를 한 번에 돈다. 배포 직후 ~1분은 새 칸을
   읽는 경로가 500 이다(fail-closed — 재시도하면 된다).
3. **서버 먼저(main)** — #938 강제 업데이트와 #944 정리는 같은 릴리스 또는 #938 뒤. 처리방침을 8판으로 올릴 때는 서버가 7·8 을
   함께 받게 먼저 낸다(`docs/spec/consent.md`).
4. **새 앱 버전(1.3) 빌드·심사** — 안드로이드 Room 이 28→31 로 오른 앱이다(응원 칸·사용 기록 2판·날짜 지정 알람). 체험 안내 문구·광고 코드(노출은 꺼짐)·음성팩
   화면·아침 소식 화면이 함께 나간다.
5. **두 스토어 게재 확인 뒤**에만 `minSupported` 를 올린다(안 그러면 받을 게 없는 강제 업데이트로 앱이 벽돌이 된다).
6. **기능 켜기는 따로** — 외부 입력이 들어온 기능부터 하나씩: 광고(§3), 공시·정책뉴스 키, 음성팩 게시, 응원 스톡 게시, 2판 계측(8판).

## 3. 중지·복구

어느 것도 계정·잔액·결과·예약을 지우지 않는다. 스톡 공개만은 멈출 수 없다(표의 그 줄). 마이그레이션은 append-only 라 **되돌리지 않는다** — 기능을 끄는 것으로 멈춘다.

| 기능 | 멈추는 법 | 남는 것 |
| --- | --- | --- |
| 스토어 무료 체험 | Play: 오퍼 `free-trial-1m` 비활성화. App Store: 첫 구독 오퍼 종료일 지정 | 이미 시작한 체험·구독은 스토어 규칙대로 이어진다 |
| 관리자 지급 | 콘솔 사용자 상세에서 지급 하나씩 회수 | 5분 크론이 정리 — 다른 권한이 없으면 클론 반납 + 3일 보관 |
| 보상형 광고 | 워커 `ADMOB_REWARDED_ADS_ENABLED` 를 끈다 → 발급·시작이 409 `AD_REWARD_UNAVAILABLE`, 앱은 제안을 숨긴다 | 이미 적립한 보상·늦은 SSV 정산은 그대로 |
| 공시·정책뉴스 | 키를 지운다 → 503, 앱은 '불러올 수 없음' 으로 그린다 | 관심 기업 목록 |
| 음성팩 | 관리자 `/admin/voice-packs` 에서 중단(이용 조건의 재생 기한) | 기존 알람은 기한까지 팩 소리, 그 뒤 앱이 미나로 바꾼다 |
| 응원·기상 인사 스톡 | ⚠ **공개(`--release`)는 되돌릴 수 없다** — 스크립트에 표식을 지우는 경로가 없고(`releaseContentSet`), 앱은 저장된 표식을 계속 읽는다(`releasedStockContentSets`). 그래서 관문은 **공개 전**이다: dev 게시·공개 → dev 앱 청취 확인 → prod. 공개 뒤 문제 문장은 `stock-content.json` 을 고쳐 다시 굽고(`preview:stock`) `--category` 로 다시 게시하면 같은 `message_id` 의 소리만 바뀐다(스크립트의 `[교체]` 갈래 — 공개 표식은 그대로). 묶음 전체를 거두려면 표식 철회 경로를 따로 개발해야 한다(이미 받은 클립·묶어 둔 알람·클론 보충이 함께 거둬지는지 검증 포함) | 이미 받은 클립 |
| 사용 기록 2판 | shared `USAGE_EVENT_DETAIL_MIN_PRIVACY_VERSION` 을 올려 서버를 배포한다 → 새 칸 저장을 멈춘다 | 1판 칸(사건·식별자)은 계속 |
| Apple 서버 알림 | ASC 에서 URL 을 지운다 | 크론 재조회가 원래 보완 경로라 그대로 돈다 |
| dev 합성 예산 | `TTS_DEV_MONTHLY_CHAR_BUDGET` 을 지운다 → 제한 없음 | — |

      `--category` 를 꼭 댄다. 공개(`--release`)는 묶음 이름이다(카테고리 `wake` → 묶음 `wake_v1`).
      ```
      npm run publish:stock -- --env dev --category cheer_v2,wake
      npm run publish:stock -- --env dev --release cheer_v2 --dry-run   # 다 올라갔는지 본다
      npm run publish:stock -- --env dev --release cheer_v2
      npm run publish:stock -- --env dev --release wake_v1
      ```
      공개 전에는 새 응원·기상 인사가 앱에 나오지 않는다. **여기서는 dev 만** 한다 — 운영 DB 에는 렌더 지문(#139)·공개 표식 표(#143)가
      main 릴리스 뒤에야 생겨, 스크립트가 그 전에는 멈춘다. 운영 게시는 아래 'main 릴리스' 뒤 항목이다.
- [ ] **dev 합성 예산 값 넷** 정하기(§1 W12) — 안 정하면 제한 없음.
- [ ] **main 릴리스** — §2 순서. 10/31 15:00Z ~ 11/04 창을 피한다.
- [ ] **ASC 서버 알림 V2 — 운영 URL**(`https://api.alarm-talk.com/api/billing/apple/notifications`) — main 배포와 마이그레이션 #136 뒤에
      등록하고 테스트 알림 수신(로그 `outcome: test`)을 확인한다. 운영 서버에는 그 전까지 이 라우트가 없다.
- [ ] **운영 스톡 게시·공개** — main 배포와 마이그레이션 성공을 확인한 **뒤**, dev 에서 들은 그 문장 그대로 위 네 명령을 `--env prod`
      로(`--release … --dry-run` 먼저). 1.3 앱 게재 전에 끝내 둔다 — 새 앱이 받을 클립이 먼저 있어야 한다.
- [ ] **1.3 앱 빌드·심사·게재** → 게재 확인 뒤에만 `minSupported` 상향.

## 5. 바뀐 것 (사용자에게 보이는 것)

- **결제·이용권**: 새 구독자는 스토어 무료 체험 1개월(해지하지 않으면 자동 결제). 결제 카드에 체험 조건·자동 결제 안내. 관리자가
  한 사람에게 기간을 정해 플러스를 줄 수 있다(앱에 코드 칸 없음).
- **직접 입력**: 무료도 기본 목소리로 월 3회(플러스 30). 이미 만든 결과를 다시 받는 것은 세지 않는다. 같은 요청을 두 번 눌러도 한 번만
  센다. 무료 3회를 다 쓰면 광고 한 편에 한 번 더(노출은 아직 꺼짐).
- **첫 경험**: 랜딩에서 기본 목소리 4종을 바로 들어 본다. 첫 추천 테마는 응원. 문구 목록에서 운세·약은 접혀 있다. 목소리 탭에서
  '이 목소리로 새 알람 만들기'.
- **목소리 받기**: 알람을 만들 때 그 알람이 쓸 목소리 하나만 준비되면 된다(나머지는 뒤에서 계속 받는다). 받는 순서는 다음 알람이 쓰는 것부터.
- **홈**: 다음 알람 상태 카드 — 권한 부족·목소리 받는 중·날씨 갱신 실패·등록 목소리 이용 종료 예정 중 지금 할 일 하나.
- **응원**: 문구 14개가 돌아가며 운다('다양하게'), 하나로 고정할 수도 있다. 짧은 기상 인사 테마(스톡 게시 뒤 보인다).
- **날짜 지정 알람**: 요일 대신 날짜 하나를 골라 그날 한 번만 우는 알람('내일 한 줄').
- **목소리 등록 녹음**: 멈추면 기기가 판정한다 — 입력 없음·너무 짧음은 다시 녹음, 말소리 적음·무음 김·작은 목소리·클리핑은 안내 뒤
  선택. 통화·이어폰 변경·백그라운드에서 녹음이 안전하게 끝난다. 공급자 장애를 녹음 탓으로 말하지 않는다.
- **아침 소식**(더보기): 관심 기업 최대 3곳의 공시와 정책뉴스, 확인 시각·출처, 고른 항목을 음성 문장으로(직접 입력과 같은 한도).
  키가 들어오기 전에는 '준비 중'.
- **음성팩**(목소리 탭 '추가 팩'): 권리를 확인한 무료 고정 목소리를 받아 기본 목소리처럼 쓴다. 게시가 끝나면 기한까지 울고 그 뒤 미나로.
  지금은 게시된 팩이 없다.
- **공개 문구**: 랜딩·FAQ·llms.txt·스토어 원문을 무료 3회·플러스 30·체험·자동 결제에 맞췄다(한·영·일).
- **눈에 안 보이는 것**: Apple 서버 알림 V2(환불·해지 즉시 반영), 합성 렌더 지문과 dev 예산(설정을 바꿔 다시 구워도 차감 0), 사용 기록
  2판과 관리자 사용 지표·광고 대조·스토어 다운로드 수, 옛 앱 호환 응답 정리(강제 업데이트 뒤).
