# 기본 목소리 대사 (스톡 클립)

기본(시스템) 목소리가 읽는 **확정 대사**의 단일 출처다. 코드는 이 문서의 구현이다 —
`packages/backend/src/lib/stock-clips.ts` 의 `STOCK_CLIP_PRESETS`.

> ⚠ 예전 원본은 `voice-preview/대사.md` 였는데 **지금 리포지터리에 없다**(코드 주석은 아직
> 그 파일을 가리킨다). 이 문서가 그 자리를 대신한다.

## 이 대사가 특별한 이유

유료 클론 문구는 Vertex 가 매번 새로 만들지만, 기본 목소리 문구는 **여기 적힌 글자 그대로**
ElevenLabs 로 간다. 합성 경로가 `prepareAlarmTextWithVertex(translate:false, autoTag:false)`
라 번역도, 자동 태깅도, **검증도 하나도 거치지 않는 순수 패스스루**다.

그래서 동적 경로에 걸어 둔 규칙(저각성 태그 금지 등)이 여기엔 자동으로 적용되지 않는다 —
**이 문서를 지키는 것이 유일한 방어선**이다.

## 규칙

1. **태그는 톤이 바뀌는 자리마다 인라인으로.** 한 줄에 보통 1~3개. 맨 앞에 하나만 두면
   ElevenLabs v3 태그가 뒤로 갈수록 풀려 **마지막 문장이 의도한 톤을 잃는다.**
2. **저각성 태그 금지.** `tired` `sleepy` `drowsy` `yawn` `whisper*` `quiet*` `soft*`
   `hushed` `calm*` `soothing` `gentle*` `mumbl` `murmur` — 깨우는 알람이라 정반대다.
   (목록의 단일 출처는 `LOW_AROUSAL_WORDS`.)
3. **숫자를 읽지 않는다.** 기온·퍼센트·환율·지수 전부. 미리 합성해 두는 문구라 오늘 수치를
   담을 수 없다. **방향과 상태만** 말한다.
4. **아이 말투(늘어진 발음)를 쓰지 않는다.** 그건 아이 목소리로 판정된 **클론** 전용 규칙이고,
   기본 목소리 4종은 전부 성인이다.
5. **4개 목소리가 같은 대사를 쓴다.** 음색 비교가 목적이라 보이스별 개별 멘트를 두지 않는다.
6. **variant 순서는 append-only.** 클라가 인덱스로 매칭하므로 순서를 바꾸면 기존 클립과
   어긋난다. 문구는 바꿔도 순서는 못 바꾼다.

## 클립 수 계산

문구가 같아도 **목소리마다 따로 합성**해야 한다. 같은 대사라도 아담이 읽은 파일과 미나가
읽은 파일은 다른 오디오다.

| | 문구 | ×3 언어 | ×4 목소리 |
| --- | ---: | ---: | ---: |
| 날씨 | 9 | 27 | 108 |
| 약 | 2 | 6 | 24 |
| 운세 | 5 | 15 | 60 |
| 사랑 | 3 | 9 | 36 |
| 기본 인사말(greeting) | 1 | 3 | 12 |
| **현재 합** | **20** | **60** | **240** |
| 주식·환율(신규 제안) | 7 | 21 | 84 |
| **추가 후 합** | **27** | **81** | **324** |

기본 목소리 4종: **아담 · 미나 · 하준 · 소은**.

**문구 종류를 등급으로 자르지 않는다**(2026-09-02). 기본 목소리도 날씨·운세·사랑·약을
고를 수 있고, 등급으로 갈리는 것은 **직접 입력 잠금 하나**다.

⚠ 다만 **'기본 인사말'(greeting)은 기본 목소리의 알람 테마가 아니다.** 여기 greeting 은
목소리 **미리듣기용 자기소개**라 매일 아침 울릴 문구가 아니고, 서버도 시스템 보이스 +
greeting 을 `INVALID_BUCKET_ID` 로 거절한다. 주려면 **기상 인사 대사를 따로** 확정해
새 카테고리로 구워야 한다. 상세는 [`docs/spec/voice-and-message.md`](../spec/voice-and-message.md) §2.

⚠ **운세·사랑의 en·ja 는 아직 한국어를 복사해 둔 임시값이다.** 그 언어 사용자에게는
뜻이 통하지 않는 오디오가 나간다 — **출시 전에 교체할 것.** 표는
`STOCK_CLIP_PLACEHOLDER_LANGUAGES`(`packages/backend/src/lib/stock-clips.ts`)에 있고,
백엔드 테스트(`test/stock-clip-placeholders.test.ts`)가 표와 실제를 **양방향**으로
대조한다 — 교체하고 표를 안 지워도, 표에 없이 복사해 넣어도 빨개진다.

# 날씨 (weather)

variant 순서는 `CLONE_WEATHER_CONDITIONS` 와 **반드시 일치**한다.
마지막 인덱스(8)는 날씨를 못 받아왔을 때의 폴백이다.

### 0 · 맑음
```
[brightly] 오늘은 하늘이 맑대요. [warmly] 나가는 길에 한 번 올려다보세요. [cheerfully] 그거 하나로 기분이 확 달라지거든요.
```

### 1 · 비
```
[caring] 오늘은 비가 온대요. [firmly] 나가기 전에 우산부터 챙기고요. [warmly] 길이 미끄러우니까 발밑도 봐 가면서 걸어요.
```

### 2 · 눈
```
[brightly] 오늘은 눈이 온대요. [caring] 따뜻하게 껴입고 나가요. [measured, deliberate] 길이 얼었을 수 있으니까, 평소보다 한 걸음씩 천천히요.
```

### 3 · 미세먼지
```
[caring] 오늘은 미세먼지가 심하대요. [firmly] 마스크 꼭 챙기세요. [warmly] 공기는 답답해도 하루는 산뜻하게 보내고요.
```

### 4 · 흐림
```
[matter-of-fact] 오늘은 하늘이 흐리대요. [caring] 비가 올 수도 있으니 작은 우산 하나 넣어 두고요. [encouraging] 날씨는 흐려도 기분까지 흐려지진 말아요.
```

### 5 · 안개
```
[concerned] 오늘 아침은 안개가 짙대요. [measured, deliberate] 앞이 잘 안 보일 수 있으니까, 서두르지 말고 천천히 가요. [warmly] 오늘은 안전이 제일이에요.
```

### 6 · 더움
```
[brightly] 오늘은 햇볕이 강하고 꽤 덥대요. [caring] 물 자주 마시고요. [firmly] 한낮에는 무리하지 말고 그늘에서 좀 쉬어 가요.
```

### 7 · 추움
```
[caring] 오늘은 많이 춥대요. [firmly] 외투 단단히 챙겨 입고 나가요. [warmly] 감기 걸리면 제가 더 속상하니까요.
```

### 8 · 폴백 (날씨를 못 받아옴)
```
[apologetically] 인터넷이 안 돼서 오늘 날씨를 못 봤어요. [warmly] 나가기 전에 창밖 한 번만 확인해 주세요. [cheerfully] 그래도 오늘 하루, 잘 다녀와요!
```

# 운세 (fortune) — 구현됨 (en·ja 는 임시)

유료 클론과 **같은 5종**이다(`CLONE_FORTUNE_THEMES` 순서: luck / caution / wealth / health / relationship).
variant 인덱스가 그 순서와 일치해야 클라가 사주+날짜로 고른 테마와 맞는다.

⚠ **개인정보를 읽지 않는다.** 사주·생년월일은 클라가 **인덱스를 고르는 데만** 쓰고, 문구
자체는 누구에게나 맞는 말이어야 한다. 오락용이라는 것도 문장이 스스로 드러내야 한다.

### 0 · 전반적으로 운이 좋은 날
```
[brightly] 오늘은 운이 좋은 날이래요. [cheerfully] 기대해도 좋겠는데요? [warmly] 좋은 일 있으면 저한테도 얘기해 주세요.
```

### 1 · 서두름만 조심
```
[matter-of-fact] 오늘은 작은 실수만 조심하면 괜찮은 날이래요. [measured, deliberate] 서두르지 말고 하나씩 하면 다 잘될 거예요. [warmly] 천천히 가요.
```

### 2 · 재물운
```
[playfully] 오늘은 재물운이 살짝 따른대요. [lightly] 뜻밖의 좋은 소식이 있을지도 모르고요. [matter-of-fact] 재미로 듣는 거예요, 너무 믿진 말고요.
```

### 3 · 컨디션
```
[caring] 오늘은 몸을 잘 챙기면 좋은 날이래요. [firmly] 무리하지 말고, 피곤하면 잠깐이라도 쉬어요. [warmly] 건강이 먼저예요.
```

### 4 · 사람 사이
```
[brightly] 오늘은 사람들과 기분 좋은 일이 있을 수 있대요. [warmly] 먼저 다정하게 건네 보세요. [cheerfully] 돌아오는 게 더 클지도 몰라요.
```

# 사랑 (love) — 구현됨 (en·ja 는 임시)

유료 클론과 **같은 3종**이다.

⚠ **기본 목소리는 연인이 아니다.** 유료 클론은 사용자가 등록한 실제 사람 목소리라 사적인
반말이 성립하지만, 기본 목소리는 앱이 주는 목소리다. **응원·다정함까지만** 가고 연애 감정
표현으로 넘어가지 않는다 — 넘어가면 기본 목소리 4종이 갑자기 사귀는 사이처럼 말한다.

### 0 · 응원
```
[warmly] 오늘도 곁에서 응원하고 있어요. [encouraging] 어떤 하루가 되든, 잘 해낼 거예요. [cheerfully] 힘내요!
```

### 1 · 보고 싶었다 · 끼니 챙기기
```
[warmly] 좋은 아침이에요. 오늘도 잘 지내고 있죠? [caring] 밥 거르지 말고 꼭 챙겨 드세요. [cheerfully] 그거면 하루가 달라져요.
```

### 2 · 기대도 된다
```
[caring] 힘든 일이 있으면 혼자 담아 두지 말아요. [warmly] 기댈 곳은 늘 있어요. [encouraging] 오늘도 제가 응원할게요.
```

# 주식·환율 (market) — 신규 제안, 미구현

⚠ **아직 코드에 없다.** 아래는 제안이고, 넣으려면 결정할 것이 세 가지 있다(문서 끝 참조).

### 0 · 미국 증시 상승
```
[brightly] 어젯밤 미국 증시는 오름세로 마감했대요. [warmly] 기분 좋게 하루 시작해 봐요. [matter-of-fact] 그래도 오늘은 오늘이니까, 너무 들뜨진 말고요.
```

### 1 · 미국 증시 하락
```
[matter-of-fact] 어젯밤 미국 증시는 내림세로 마감했대요. [encouraging] 이런 날도 있는 거죠. [warmly] 숫자에 너무 흔들리지 말고, 오늘 할 일부터 챙겨요.
```

### 2 · 미국 증시 혼조
```
[matter-of-fact] 어젯밤 미국 증시는 오르내림이 엇갈렸대요. [lightly] 방향이 뚜렷하지 않은 날이에요. [warmly] 서두를 것 없이 천천히 살펴봐요.
```

### 3 · 환율 상승 (원화 약세)
```
[matter-of-fact] 오늘 아침 환율은 어제보다 올랐대요. [caring] 해외 결제나 여행 준비가 있다면 한 번 확인해 보세요. [warmly] 오늘도 좋은 하루 보내고요.
```

### 4 · 환율 하락 (원화 강세)
```
[brightly] 오늘 아침 환율은 어제보다 내렸대요. [lightly] 미뤄 뒀던 해외 결제가 있다면 오늘 볼 만하겠네요. [warmly] 좋은 하루 보내요.
```

### 5 · 환율 보합
```
[matter-of-fact] 오늘 아침 환율은 어제와 비슷하대요. [lightly] 급하게 움직일 일은 없어 보여요. [warmly] 편하게 하루 시작해요.
```

### 6 · 폴백 (시장 정보를 못 받아옴)
```
[apologetically] 인터넷이 안 돼서 오늘 시장 소식은 못 받아 왔어요. [warmly] 필요하면 나중에 직접 확인해 보세요. [cheerfully] 오늘 하루도 잘 다녀와요!
```

## 왜 숫자도 조언도 없는가

- **숫자**: 미리 합성해 두는 문구라 오늘 수치를 담을 수 없다. 날씨가 "26도"라고 말하지 않는
  것과 같은 이유이고, 프롬프트 규약 자체가 숫자·퍼센트 낭독을 금지한다.
- **조언**: "사세요/파세요" 류가 들어가면 **투자 조언**으로 읽힌다. 스토어 심사에서 걸리고,
  틀렸을 때 책임 문제가 된다. 그래서 방향만 전하고 "숫자에 흔들리지 말고" 로 감쌌다.

## 넣기 전에 정해야 할 것

1. **데이터 소스가 없다.** 날씨는 무료 API 로 클라가 조건을 판정하는데 증시·환율에는 그
   경로가 아예 없다. 만들지 않으면 **항상 폴백(6번)만 재생된다.**
2. **축이 둘이다**(증시 / 환율). 클라가 어느 쪽을 고를지 규칙이 필요하다. 국내 증시까지
   넣으면 3축 10종이 된다.
3. **무료 테마에 자동 편입된다.** `FREE_BUCKET_CATEGORIES` 가 `STOCK_CLIP_PRESETS` 에서
   파생되기 때문이다. 반대로 **유료 클론에는 자동으로 안 들어간다** — `PAID_BUCKET_CATEGORIES`
   는 별도 목록이라 `CLONE_CLIP_SEEDS` 에 seed 를 추가하고 `CLONE_PRERENDER_TOTAL` 을
   21 → 28 로 올려야 한다.

# 문구를 바꿀 때 (운영 절차)

⚠ **텍스트만 고치고 끝나지 않는다.**

1. 이 문서를 먼저 고친다(단일 출처).
2. `STOCK_CLIP_PRESETS` 를 맞춘다.
3. **기존 프리셋 행을 무효화하는 마이그레이션**을 함께 넣는다. `findMissingStockTargets` 는
   `(voice_profile_id | category | language)` 존재 여부만 보므로, 행을 지우지 않으면
   **재시드해도 옛 문구가 그대로 남는다.**
4. 배포 후 `POST /api/admin/seed-stock-clips` 로 재생성한다.

⚠ **그 클립을 물고 있던 알람은 `sound-only` 로 떨어져 나간다** — 무료 사용자의 기존 알람이
목소리를 잃는다는 뜻이다. 선례는 마이그레이션 #45(`rename-reassign-stock-voices`).

# 다른 언어

en·ja 는 **한국어가 확정된 뒤에** 맞춘다. 세 언어는 번역이 아니라 각각 확정 리터럴이지만,
톤과 태그 배치는 같은 설계를 따른다.
