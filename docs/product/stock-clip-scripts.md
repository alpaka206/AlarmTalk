# 기본 목소리 대사 (스톡 클립)

기본(시스템) 목소리가 읽는 **확정 대사**의 단일 출처다. 코드는 이 문서의 구현이다 —
`packages/backend/src/lib/stock-clips.ts` 의 `STOCK_CLIP_PRESETS`.

> ⚠ 예전 원본은 `voice-preview/대사.md` 였는데 **지금 리포지터리에 없다**(코드 주석은 아직
> 그 파일을 가리킨다). 이 문서가 그 자리를 대신한다.

## 이 대사가 특별한 이유

유료 클론 문구는 Vertex 가 매번 새로 만들지만, 기본 목소리 문구는 **여기 적힌 글자 그대로**
ElevenLabs 로 간다. 합성 경로가 `prepareAlarmTextWithVertex(translate:false, autoTag:false)`
라 번역도, 자동 태깅도, **검증도 하나도 거치지 않는 순수 패스스루**다.

그래서 동적 경로에 걸어 둔 규칙(저각성 태그 금지 등)이 여기엔 자동으로 적용되지 않는다 —
**이 문서를 지키는 것이 유일한 방어선**이다.

## 규칙

1. **태그는 톤이 바뀌는 자리마다 인라인으로.** 한 줄에 보통 1~3개. 맨 앞에 하나만 두면
   ElevenLabs v3 태그가 뒤로 갈수록 풀려 **마지막 문장이 의도한 톤을 잃는다.**
2. **저각성 태그 금지.** `tired` `sleepy` `drowsy` `yawn` `whisper*` `quiet*` `soft*`
   `hushed` `calm*` `soothing` `gentle*` `mumbl` `murmur` — 깨우는 알람이라 정반대다.
   (목록의 단일 출처는 `LOW_AROUSAL_WORDS`.)
3. **숫자를 읽지 않는다.** 기온·퍼센트·환율·지수 전부. 미리 합성해 두는 문구라 오늘 수치를
   담을 수 없다. **방향과 상태만** 말한다.
4. **아이 말투(늘어진 발음)를 쓰지 않는다.** 그건 아이 목소리로 판정된 **클론** 전용 규칙이고,
   기본 목소리 4종은 전부 성인이다.
5. **4개 목소리가 같은 대사를 쓴다.** 음색 비교가 목적이라 보이스별 개별 멘트를 두지 않는다.
6. **variant 순서는 append-only.** 클라가 인덱스로 매칭하므로 순서를 바꾸면 기존 클립과
   어긋난다. 문구는 바꿔도 순서는 못 바꾼다.

## 클립 수 계산

문구가 같아도 **목소리마다 따로 합성**해야 한다. 같은 대사라도 시우가 읽은 파일과 미나가
읽은 파일은 다른 오디오다.

| | 문구 | ×3 언어 | ×4 목소리 |
| --- | ---: | ---: | ---: |
| 날씨 | 9 | 27 | 108 |
| 약 | 2 | 6 | 24 |
| 운세 | 5 | 15 | 60 |
| 응원 | 3 | 9 | 36 |
| 기본 인사말(greeting) | 1 | 3 | 12 |
| **현재 합** | **20** | **60** | **240** |
| 주식·환율(신규 제안) | 7 | 21 | 84 |
| **추가 후 합** | **27** | **81** | **324** |

기본 목소리 4종: **시우 · 미나 · 도현 · 애니**(2026-09-03 전면 교체).

| 이름 | 결 | 비고 |
| --- | --- | --- |
| 시우 | 밝은 소년미 | 한국어 원어 |
| 미나 | 차분·따뜻 | 한국어 원어. 교체 전부터 쓰던 목소리 |
| 도현 | 따뜻하고 단단한 어른 | 한국어 verified |
| 애니 | 발랄한 애니 캐릭터 | 내부 식별자·파일명은 `narin` 이다(아래 ⚠) |

⚠ **'애니' 의 내부 식별자·파일명은 `narin` 이다.** 표시 이름만 바꿨다 — '애니' 를
식별자로 쓰면 코드 곳곳의 '애니메이션' 과 검색에서 뒤섞인다. 표시 이름은 제품이 정하고
식별자는 안정적으로 둔다.

⚠ **네 칸이 서로 다른 사람이어야 한다.** 교체 전에는 넷 중 둘이 영어권 premade 목소리로
한국어를 읽고 있었고(`아담`=Adam 그대로, `소은`=Jessica 에 이름만 덧씌움), 나머지 둘도
'젊고 도시적' 으로 결이 겹쳐 **선택지가 사실상 둘**이었다. 지금은 소년미 / 차분 / 어른 /
발랄로 갈린다 — 목소리를 새로 고를 때 이 네 축이 무너지지 않는지 먼저 본다.

⚠ **목소리를 바꾸면 내장 미리듣기 mp3 도 함께 바꾼다**(`res/raw/voice_greeting_*`,
4목소리 × 3언어 = 12개). 그 파일은 앱에 번들돼 있어서 서버 클립만 다시 구우면
**미리듣기에서만 옛 목소리가 남는다.** iOS 는 Android `res/raw` 를 직접 참조하므로
(`project.yml`) 안드로이드 쪽만 바꾸면 양쪽에 반영된다.

**문구 종류를 등급으로 자르지 않는다**(2026-09-02). 기본 목소리도 날씨·운세·사랑·약을
고를 수 있고, 등급으로 갈리는 것은 **직접 입력 잠금 하나**다.

⚠ 다만 **'기본 인사말'(greeting)은 기본 목소리의 알람 테마가 아니다.** 여기 greeting 은
목소리 **미리듣기용 자기소개**라 매일 아침 울릴 문구가 아니고, 서버도 시스템 보이스 +
greeting 을 `INVALID_BUCKET_ID` 로 거절한다. 주려면 **기상 인사 대사를 따로** 확정해
새 카테고리로 구워야 한다. 상세는 [`docs/spec/voice-and-message.md`](../spec/voice-and-message.md) §2.

**세 언어 대사가 모두 확정됐다**(2026-09-02). 한국어·영어·일본어가 각각 그 언어의 확정
리터럴이고, 번역이 아니다 — 합성 경로가 `translate:false` 라 여기 적힌 글자가 그대로
ElevenLabs 로 간다.

⚠ **문구를 고치면 옛 클립을 무효화하는 마이그레이션을 반드시 함께 넣는다.**
`findMissingStockTargets` 는 존재 여부만 보므로, 안 지우면 재시드해도 옛 문구가 남는다.
`STOCK_PRESET_TEXTS_FINGERPRINT`(`lib/migrations.ts`)가 그걸 강제한다 — 문구가 바뀌면
테스트가 그 상수로 사람을 데려온다.

# 날씨 (weather)

### 0 · 맑음
```
[brightly] 오늘은 괜히 어디론가 나가고 싶어질 만큼 날씨가 좋대요. [warmly] 이런 날 계속 누워 있기엔 좀 아깝잖아요. [encouraging] 슬슬 일어나서... 산책이라도 하러 가볼까요?
```

### 1 · 비
```
[warmly] 오늘은 비가 올 수 있대요. 비 오는 날엔 빗소리 들으면서 조금만 더 누워 있고 싶어지죠... [encouraging] 그래도 이제 슬슬 일어나 볼까요? [caring] 나갈 때는 우산 꼭 챙겨요.
```

### 2 · 눈
```
[brightly] 오늘은 눈이 올 수 있대요. 눈 내리는 건 가만히 바라보는 것만으로도 참 예쁜 것 같아요. [encouraging] 일단 이불부터 걷고, 창밖을 한 번 볼까요? [caring] 나갈 때는 따뜻하게 입고, 길이 미끄러울 수 있으니까 천천히 가요.
```

### 3 · 미세먼지
```
[caring] 오늘은 미세먼지가 심하대요. 겉으로는 괜찮아 보여도 공기가 답답할 수 있어요. [firmly] 이런 날은 조금 귀찮더라도 마스크 꼭 챙겨요. [encouraging] 공기는 좀 답답하더라도 아침은 힘차게 시작해 볼까요?
```

### 4 · 흐림
```
[warmly] 오늘은 하늘이 흐리대요. 이런 날은 아침이 와도 괜히 더 누워 있고 싶어지죠. [encouraging] 그래도 계속 누워 있으면 더 일어나기 싫어질 테니까... [brightly] 일단 커튼부터 열고, 하루를 시작해 볼까요?
```

### 5 · 안개
```
[concerned] 오늘 아침은 안개가 짙대요. 앞이 잘 안 보이면 평소보다 가는 데 시간이 조금 더 걸릴 수도 있어요. [encouraging] 조금 여유 있게 준비하려면, 이제 일어나야겠죠? [firmly] 나갈 때는 앞을 잘 살피고, 서두르지 말고 천천히 가요.
```

### 6 · 더움
```
[warmly] 오늘은 정말 덥대요. 이런 날은 에어컨 바람만 쐬면서 하루 종일 쉬고 싶어지죠. [encouraging] 그래도 더 더워지기 전에 슬슬 일어나 볼까요? [caring] 물 자주 마시고, 한낮에는 너무 무리하지 말아요.
```

### 7 · 추움
```
[caring] 오늘은 많이 춥대요. 이런 날은 이불 밖으로 나오기가 정말 싫어지죠. [warmly] 그래도 따뜻한 물로 세수하면 잠이 조금 깰 거예요... 이제 용기 내서 일어나 볼까요? [caring] 나갈 때는 옷 따뜻하게 챙겨 입는 것도 잊지 말고요.
```

### 8 · 폴백 (날씨를 못 받아옴)
```
[apologetically] 오늘은 날씨 정보를 불러오지 못했어요. [caring] 나가기 전에 창밖을 한 번 보고, 날씨도 꼭 확인해 주세요. [cheerfully] 날씨는 못 알려 드렸지만... 이제 슬슬 일어나서 오늘을 시작해 볼까요?
```

# 운세 (fortune)

유료 클론과 **같은 5종**이다(`CLONE_FORTUNE_THEMES` 순서: luck / caution / wealth / health / relationship).
variant 인덱스가 그 순서와 일치해야 클라가 사주+날짜로 고른 테마와 맞는다.

⚠ **개인정보를 읽지 않는다.** 사주·생년월일은 클라가 **인덱스를 고르는 데만** 쓰고, 문구
자체는 누구에게나 맞는 말이어야 한다. 오락용이라는 것도 문장이 스스로 드러내야 한다.

### 0 · 전반적으로 운이 좋은 날
```
[playfully] 오늘은 운이 좀 따라주는 날이래요. 생각보다 일이 술술 풀릴지도 모르겠네요. [brightly] 미뤄 둔 일이 있다면, 오늘은 가볍게 한 번 해봐도 좋겠어요.
```

### 1 · 서두름만 조심
```
[warmly] 오늘은 서두르지만 않으면 괜찮게 흘러갈 거래요. 마음이 급하면 평소엔 안 하던 실수도 나오잖아요. [encouraging] 오늘은 한 박자만 늦춰서, 하나씩 확인하면서 해봐요.
```

### 2 · 재물운
```
[playfully] 오늘은 재물운이 조금 따라준대요. 뜻밖에 돈을 아낄 일이 생기거나, 생각지도 못한 곳에서 작은 이득을 볼지도 모르겠네요. [brightly] 이왕이면... 로또 같은 큰 행운까지 따라오면 정말 좋겠는데요?
```

### 3 · 컨디션
```
[caring] 오늘은 몸 상태를 조금 더 잘 살피는 게 좋대요. 괜찮다고 넘긴 피로가 나중에 한꺼번에 몰려올 수도 있거든요. [warmly] 평소보다 조금 천천히 움직이고, 지치면 잠깐 쉬어 가요.
```

### 4 · 사람 사이
```
[brightly] 오늘은 사람들과 기분 좋은 일이 생길 수 있대요. 가볍게 건넨 한마디가 생각보다 좋은 분위기를 만들지도 모르겠네요. [warmly] 문득 떠오르는 사람이 있다면, 먼저 안부를 전해 봐요.
```

# 응원 (love)

⚠ **표시 이름은 「응원」인데 카테고리 id 는 `love` 다**(2026-09-02). 대사가 응원 문구로
확정되면서 이름만 바꿨다 — id 는 `messages.category`·`alarms.bucket_id`·서버
`TTS_CATEGORIES` 에 **이미 저장된 행으로 존재**하므로 바꾸지 않는다.

⚠ **연애 문구가 아니다.** 기본 목소리는 앱이 주는 목소리다. 예전 대사는 "사랑하는 마음을
담아" 였는데, 그러면 기본 목소리 4종이 갑자기 사귀는 사이처럼 말한다. 지금 대사는
**응원·자기돌봄**이고 유료 클론도 같은 3종을 쓴다.

### 0 · 응원
```
[warmly] 해야 할 일이 많으면 시작하기도 전에 마음부터 바빠지잖아요. [caring] 그렇다고 처음부터 전부 잘할 필요는 없어요. [encouraging] 지금 할 수 있는 것부터 하나씩 해봐요. 하다 보면 생각보다 잘 풀릴지도 모르니까요.
```

### 1 · 나부터 챙기기
```
[warmly] 이것저것 신경 쓰다 보면 정작 스스로를 챙기는 건 자꾸 뒤로 미루게 되죠. [caring] 바쁘더라도 밥은 꼭 챙겨 먹고, 지치면 잠깐이라도 쉬어요. [encouraging] 그래야 하고 싶은 일도 오래 할 수 있잖아요.
```

### 2 · 혼자 버티지 않기
```
[caring] 힘든 일이 생겨도 혼자 괜찮은 척할 필요는 없어요. [warmly] 믿을 만한 사람에게 슬쩍 털어놓으면 생각보다 마음이 가벼워질 때도 있거든요. [encouraging] 너무 혼자 버티려고만 하지는 말아요.
```

# 주식·환율 (market) — 신규 제안, 미구현

⚠ **아직 코드에 없다.** 아래는 제안이고, 넣으려면 결정할 것이 세 가지 있다(문서 끝 참조).

### 0 · 미국 증시 상승
```
[brightly] 어젯밤 미국 증시는 오름세로 마감했대요. [warmly] 기분 좋게 하루 시작해 봐요. [matter-of-fact] 그래도 오늘은 오늘이니까, 너무 들뜨진 말고요.
```

### 1 · 미국 증시 하락
```
[matter-of-fact] 어젯밤 미국 증시는 내림세로 마감했대요. [encouraging] 이런 날도 있는 거죠. [warmly] 숫자에 너무 흔들리지 말고, 오늘 할 일부터 챙겨요.
```

### 2 · 미국 증시 혼조
```
[matter-of-fact] 어젯밤 미국 증시는 오르내림이 엇갈렸대요. [lightly] 방향이 뚜렷하지 않은 날이에요. [warmly] 서두를 것 없이 천천히 살펴봐요.
```

### 3 · 환율 상승 (원화 약세)
```
[matter-of-fact] 오늘 아침 환율은 어제보다 올랐대요. [caring] 해외 결제나 여행 준비가 있다면 한 번 확인해 보세요. [warmly] 오늘도 좋은 하루 보내고요.
```

### 4 · 환율 하락 (원화 강세)
```
[brightly] 오늘 아침 환율은 어제보다 내렸대요. [lightly] 미뤄 뒀던 해외 결제가 있다면 오늘 볼 만하겠네요. [warmly] 좋은 하루 보내요.
```

### 5 · 환율 보합
```
[matter-of-fact] 오늘 아침 환율은 어제와 비슷하대요. [lightly] 급하게 움직일 일은 없어 보여요. [warmly] 편하게 하루 시작해요.
```

### 6 · 폴백 (시장 정보를 못 받아옴)
```
[apologetically] 인터넷이 안 돼서 오늘 시장 소식은 못 받아 왔어요. [warmly] 필요하면 나중에 직접 확인해 보세요. [cheerfully] 오늘 하루도 잘 다녀와요!
```

## 왜 숫자도 조언도 없는가

- **숫자**: 미리 합성해 두는 문구라 오늘 수치를 담을 수 없다. 날씨가 "26도"라고 말하지 않는
  것과 같은 이유이고, 프롬프트 규약 자체가 숫자·퍼센트 낭독을 금지한다.
- **조언**: "사세요/파세요" 류가 들어가면 **투자 조언**으로 읽힌다. 스토어 심사에서 걸리고,
  틀렸을 때 책임 문제가 된다. 그래서 방향만 전하고 "숫자에 흔들리지 말고" 로 감쌌다.

## 넣기 전에 정해야 할 것

1. **데이터 소스가 없다.** 날씨는 무료 API 로 클라가 조건을 판정하는데 증시·환율에는 그
   경로가 아예 없다. 만들지 않으면 **항상 폴백(6번)만 재생된다.**
2. **축이 둘이다**(증시 / 환율). 클라가 어느 쪽을 고를지 규칙이 필요하다. 국내 증시까지
   넣으면 3축 10종이 된다.
3. **무료 테마에 자동 편입된다.** `FREE_BUCKET_CATEGORIES` 가 `STOCK_CLIP_PRESETS` 에서
   파생되기 때문이다. 반대로 **유료 클론에는 자동으로 안 들어간다** — `PAID_BUCKET_CATEGORIES`
   는 별도 목록이라 `CLONE_CLIP_SEEDS` 에 seed 를 추가하고 `CLONE_PRERENDER_TOTAL` 을
   21 → 28 로 올려야 한다.

# 문구를 바꿀 때 (운영 절차)

⚠ **텍스트만 고치고 끝나지 않는다.**

1. 이 문서를 먼저 고친다(단일 출처).
2. `STOCK_CLIP_PRESETS` 를 맞춘다.
3. **기존 프리셋 행을 무효화하는 마이그레이션**을 함께 넣는다. `findMissingStockTargets` 는
   `(voice_profile_id | category | language)` 존재 여부만 보므로, 행을 지우지 않으면
   **재시드해도 옛 문구가 그대로 남는다.**
4. 배포 후 `POST /api/admin/seed-stock-clips` 로 재생성한다.

⚠ **그 클립을 물고 있던 알람은 `sound-only` 로 떨어져 나간다** — 무료 사용자의 기존 알람이
목소리를 잃는다는 뜻이다. 선례는 마이그레이션 #45(`rename-reassign-stock-voices`).
