# 음성 알람 프롬프트 고도화 — 스크럼 요약 (1p)

## 뭐를 / 왜
음성 알람 문구 생성(Gemini→ElevenLabs v3)을 전면 재설계. **"같은 조건인데 결과가 들쭉날쭉/밋밋", "일본어가 어색", "v3 태그 안 맞음"** 해결. 알라미(게임) 대비 **음성**으로 차별화.

## 진단 (근본 원인)
1. 🐞 **검증된 버그** — `elevenlabs.ts:119`가 v3에 `voice_settings`를 **안 보냄** → 서버 디폴트 적용돼 태그가 약하게 실현.
2. **일본어 가이드 0줄** (한국어는 ~114줄). 가족/친밀 일본어는 **タメ口(캐주얼)** 인데 한국어 존댓말을 직역 → 어색.
3. **들쭉날쭉 원인** = 고온도(0.85) 생성 + 정규식 8개가 대부분 **통째 폐기 → 고정 폴백**.
4. **가짜 태그** — `[warmly][encouraging]…`는 v3 실제 어휘 아님.
5. 동적모드 **이중 호출 + 순환 태그 모순**, 날씨 항상 한국어.

## 설계 (핵심)
- **언어-네이티브-우선 단발**: 호출 1회로 `{text, tag}`. systemInstruction에 철학·계약 분리 + responseSchema.
- **일본어 네이티브 규칙 신설**: タメ口 디폴트(가족/친밀), 종조사 ね/よ/な, 강한 pro-drop, 役割語 금지, 가타카나, 모라.
- **태그 정합**: v3 태그는 **enum이 아니라 자연어 지시**(2026-06-28 검증) — 우리는 큐레이트된 실증 큐만 사용: 가짜 10종 폐기 → `[happy][cheerfully][excited][playfully][curious][lighthearted][calm][tired][whispers][quietly]`. 저각성(calm/tired/whispers/quietly)은 **sleep 전용**. (실서비스 전이라 마이그레이션 맵 없이 그냥 교체)
- **검증 2단화**: binary 폐기 → **HARD 차단/SOFT 수리**(폐기 대신 국소 수리). → 들쭉날쭉 해소.
- **voice_settings 버그 수정**: v3에 항상 전송(stability 0.5 Natural).
- **soft-start·짧게·매일 변주**(opener/리듬만, 골격 고정).

## 검증된 사실 vs 가설
- ✅ 확정: voice_settings 미전송, 이중호출·순환모순, 일본어 0줄, 과폐기, 날씨 한국어 고정.
- ❓ 가설(출시 전 실측): 태그 어휘의 v3 실제 반응, 픽스가 태그 되살리는지, **KO/JA v3 합성 MOS**, 길이 스위트스팟.

## 결정 필요 (PO/팀)
