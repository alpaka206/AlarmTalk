## 3. 제약사항

### 외부 API 비용
- **Perso.ai**: 음성 클론 + TTS 호출당 과금 — 현재 API 404 상태 (미연동)
- **ElevenLabs**: 보조 TTS — 현재 미연동
- **FCM**: 무료 (일 전송량 제한 없음)

### 무료 티어 제한
- **Cloudflare Workers**: 일 100,000 요청, 10ms CPU 시간/요청
- **Turso DB**: 9GB 스토리지, 500M 행 읽기/월
- **R2 스토리지**: 10GB 무료, 1M Class A + 10M Class B 작업/월

### 플랫폼 제한
- iOS: 백그라운드 알람은 로컬 알림(expo-notifications) 의존
- Android: 정확한 알람은 `AlarmManager` 필요 (expo-notifications가 내부적으로 처리)
- 음성 녹음: 마이크 권한 필수
- 푸시 알림: 알림 권한 필수
