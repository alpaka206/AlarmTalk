AlarmTalk(이하 "알람톡")은 베일런(Vailen, 이하 "회사")이 운영하는, 사용자가 선택한 목소리로 알람을 설정하고 가족 또는 파트너와 음성을 공유할 수 있는 OS 네이티브 음성 알람 서비스입니다. 알람톡은 알람이 울리는 핵심 경로에서 서버 호출, 푸시 알림, 실시간 네트워크 연결에 의존하지 않도록 설계합니다. 다만 계정, 동기화, 음성 등록, AI 음성 생성, 가족 공유, 오류 분석, 고객지원 기능을 제공하기 위해 필요한 개인정보를 처리합니다.

알람톡은 개인정보 보호법, 정보통신망 관련 법령, 앱 마켓 정책 등 관련 기준에 따라 개인정보를 처리하며, 본 처리방침은 알람톡이 어떤 정보를 수집하고 어떻게 이용, 보관, 이전, 파기하는지 설명합니다.

## 1. 처리하는 개인정보 항목

알람톡은 서비스 제공에 필요한 범위에서 다음 정보를 처리합니다.

### 1.1 계정 및 인증

- 필수: 이메일 주소, 비밀번호 해시, 닉네임, 사용자 식별자, 가입일, 로그인 방식, 인증 토큰
- Google 로그인 사용 시: Google 계정 식별자, Google ID 토큰 검증 결과, 이메일 주소
- Apple 로그인(Sign in with Apple) 사용 시: Apple 계정 식별자, Apple ID 토큰 검증 결과, 이메일 주소, 최초 로그인 시 사용자가 제공에 동의한 이름
  - Apple 로그인은 iOS 앱에서만 제공합니다. 사용자가 '나의 이메일 가리기'를 선택하면 Apple이 제공하는 익명 전달 주소(@privaterelay.appleid.com)를 이메일 주소로 처리하며, 회사는 실제 이메일 주소를 알 수 없습니다.
  - Apple은 이름을 최초 1회 로그인에만 제공하므로, 그 시점에 전달받은 이름만 처리합니다.
- 이메일 인증 사용 시: 인증 코드 발송 및 검증 기록, 인증 시각
- 목적: 회원 식별, 로그인, 계정 보호, 세션 유지, 고객지원, 부정 이용 방지

알람톡은 비밀번호 원문을 저장하지 않습니다.

### 1.2 알람 설정 및 사용 기록

- 필수: 알람 시간, 반복 요일, 활성 여부, 스누즈 시간, 진동 설정, 알람 재생 모드, 알람음/음성 선택 정보, 다음 울림 예정 시각
- 선택: 알람 제목, 가족/파트너가 보낸 알람 여부, 수신 거부 상태
- 목적: 알람 생성, 수정, 삭제, 동기화, 복원, 가족 알람 전달

알람이 실제로 울리는 순간에는 기기 안의 로컬 데이터와 로컬 음성 파일을 사용합니다. 서버 장애나 네트워크 연결 여부는 핵심 알람 울림 경로의 필수 조건이 아닙니다.

### 1.3 음성 녹음, 파일 업로드, AI 음성 생성 (민감정보 · 생체정보)

- 사용자가 직접 제공하는 정보: 직접 녹음한 음성, 선택 또는 업로드한 오디오 파일, 잘라낸 음성 구간, 파일 형식, 파일 길이, 음성 프로필 이름
- AI 기능 사용 시: 음성 프로필 식별자, 음성 클론 제공자 식별자, TTS 입력 문구, 생성된 음성 파일, 생성 메시지 식별자, 생성 캐시 키
- 공유 설정 사용 시: 음성 공유 여부, 공유 대상 그룹, 공유 또는 수신된 음성 식별자
- 목적: 알람용 음성 등록, 음성 프로필 생성, TTS 알람 문구 생성, 로컬 알람 재생을 위한 캐싱, 가족/파트너 그룹 내 공유
- 분류 및 동의: **민감정보 · 생체정보**(개인정보 보호법 제23조). 음성 클론(목소리 등록)은 개인을 식별·재현할 수 있는 생체정보 처리에 해당하므로 **음성 생체정보 처리에 대한 별도 동의** 없이는 클로닝이 시작되지 않습니다. 이 동의는 회원가입 시 별도 항목으로 받으며(선택 항목이므로 동의하지 않아도 가입과 기본 목소리 알람 이용에는 지장이 없습니다), 음성 처리 경로에서 서버가 다시 확인합니다.

**동의를 철회하면** 등록한 음성 프로필, 업로드한 원본 녹음, 생성된 음성 파일, 저장한 알람 문구가 **즉시 삭제되며 복구할 수 없습니다.** 그 목소리로 울리던 알람은 가족·파트너에게 공유한 알람까지 기본 알람음으로 변경됩니다. 다시 이용하려면 목소리를 처음부터 새로 등록해야 합니다.

알람톡은 음성 데이터에 개인의 목소리 특성이 포함되며, 음성 클론을 통해 개인을 식별·재현할 수 있다는 점에서 이를 **민감정보이자 생체정보**로 분류합니다. 음성 클론(목소리 등록) 기능은 이용자가 목소리를 등록하기 전에 별도의 음성 생체정보 처리 동의를 한 경우에만 동작하며, 동의가 없으면 서버가 클로닝 요청을 차단합니다. 회사(베일런)는 음성 데이터를 사용자 본인 확인이나 인증 목적의 신원확인용 생체인식정보로 사용하지 않으며, 광고 타게팅이나 데이터 판매 목적으로 사용하지 않습니다. 음성 클론 및 TTS 생성은 음성 AI 제공자(제5조의 ElevenLabs)를 통해 처리되며, 제공자의 구체적 처리 조건은 실제 적용 계약과 정책을 따릅니다.

### 1.4 지역 및 동적 문구 설정

- 사용자가 직접 선택·입력한 경우: 국가, 도시, 날씨/운세 문구 설정값
- 운세(사주) 문구 기능 사용 시: **성별, 생년월일, 출생 시각(시·분)** — 목적: 운세 기반 동적 알람 문구 생성 / 수탁·국외 이전: 알람 문구 동적 생성을 위해 해당 항목이 Google Cloud Vertex AI(미국)로 전송됨(제5조 참고)
- 목적: 사용자가 요청한 날씨 기반 알람 문구, 운세 기반 동적 문구, 지역 기반 동적 문구, 설정 저장

알람톡은 단말기 GPS나 통신망 기반 위치를 자동으로 수집하지 않습니다. 지역 정보는 사용자가 국가와 도시를 직접 선택한 값만 처리하며, 이는 「위치정보의 보호 및 이용 등에 관한 법률」상 개인위치정보에 해당하지 않습니다.

이용자가 동적(랜덤) 알람 문구 또는 다국어 번역 기능을 사용하면, 알람 문구 생성·번역을 위해 알람 텍스트와 위 운세 정보(성별·생년월일·출생 시각)가 Google Cloud Vertex AI(Gemini, 미국)로 전송되어 처리됩니다. 운세 정보는 문구의 분위기를 정하기 위한 내부 입력으로만 사용되며, 생성된 알람 문구에 생년월일·출생 시각 등 원본 값이 그대로 노출되지 않도록 필터링합니다. 동적 문구·번역 기능을 사용하지 않으면 이 전송은 발생하지 않습니다.

### 1.5 가족/파트너 공유

- 필수: 초대 코드, 초대 상태, 그룹 식별자, 그룹 구성원 식별자, 공유 음성 식별자, 받은 알람/메시지 기록
- 목적: 가족/파트너 그룹 생성, 초대 수락, 그룹 내 음성 공유, 상대방 알람 설정, 받은 메시지 재생

알람톡은 음성 데이터를 공개 검색, 그룹 밖 공개 공유, 외부 다운로드 목적으로 제공하지 않습니다.

### 1.6 결제 및 이용권

- 결제 기능 사용 시: 요금제, 구독 상태, 상품 식별자, 결제 제공자, 결제/해지/갱신 상태, 이용권 또는 쿠폰 사용 기록
- 목적: 유료 기능 제공, 이용권 관리, 환불/해지 처리, 부정 이용 방지

알람톡 서버는 카드번호, 계좌번호 등 결제수단 전체 정보를 저장하지 않습니다. 결제는 앱 마켓의 인앱결제로 이루어집니다 — Android 앱은 Google Play 인앱결제, iOS 앱은 App Store 인앱결제를 사용하며, 결제 처리와 환불은 각 마켓의 정책과 절차에 따릅니다.

### 1.7 고객지원, 보안, 오류 분석

- 필수 또는 자동 수집: 문의 내용, 답변 이메일, 요청 시각, 접속 IP, User-Agent, API 요청 경로, 오류 코드, 기기 OS, 앱 버전, 빌드 버전, 오류 로그, 보안 이벤트
- 선택: 사용자가 첨부한 스크린샷, 로그, 재현 설명
- 목적: 고객 문의 처리, 장애 분석, 보안 사고 대응, 부정 이용 방지, 서비스 안정성 개선

오류 분석 도구에는 오류 원인 파악에 필요한 최소한의 진단 정보만 전송되도록 설정하며, 비밀번호 원문, 결제수단 전체 정보, 주민등록번호 등 고유식별정보를 수집하지 않습니다.

## 2. 개인정보 처리 목적

알람톡은 다음 목적을 위해 개인정보를 처리합니다.

- 회원 가입, 로그인, 계정 보호, 본인 확인
- OS 네이티브 알람 설정, 동기화, 복원, 로컬 재생
- 음성 녹음, 업로드, 음성 프로필 생성, TTS 생성
- 가족/파트너 초대, 그룹 내 음성 공유, 상대방 알람 설정
- 날씨·운세 등 사용자가 켠 동적 문구 기능 제공
- 요금제별 이용권 제한 적용
- 결제, 구독, 이용권, 환불, 해지 처리
- 고객지원, 공지, 약관 및 정책 변경 안내
- 장애 분석, 보안, 부정 이용 방지, 법령상 의무 이행

회사(베일런)는 이용자의 음성 녹음, 업로드 파일, 생성 음성을 회사가 직접 운영하는 별도의 범용 AI 모델 학습에 사용하지 않습니다. 다만 음성 클론·TTS 기능 제공을 위해 음성 AI 제공자(ElevenLabs)에게 처리를 위탁하며, 해당 제공자는 실제 적용 계약과 정책에 따라 서비스 제공, 보안, 품질 관리, 장애 대응에 필요한 범위에서 데이터를 처리할 수 있습니다(제5조·제6조).

미리 알려 드립니다.
