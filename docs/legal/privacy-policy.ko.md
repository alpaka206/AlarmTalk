AlarmTalk(이하 "알람톡")은 베일런(Vailen, 이하 "회사")이 운영하는, 사용자가 선택한 목소리로 알람을 설정하고 가족 또는 파트너와 음성을 공유할 수 있는 OS 네이티브 음성 알람 서비스입니다. 알람톡은 알람이 울리는 핵심 경로에서 서버 호출, 푸시 알림, 실시간 네트워크 연결에 의존하지 않도록 설계합니다. 다만 계정, 동기화, 음성 등록, AI 음성 생성, 가족 공유, 오류 분석, 고객지원 기능을 제공하기 위해 필요한 개인정보를 처리합니다.

알람톡은 개인정보 보호법, 정보통신망 관련 법령, 앱 마켓 정책 등 관련 기준에 따라 개인정보를 처리하며, 본 처리방침은 알람톡이 어떤 정보를 수집하고 어떻게 이용, 보관, 이전, 파기하는지 설명합니다.

## 1. 처리하는 개인정보 항목

알람톡은 서비스 제공에 필요한 범위에서 다음 정보를 처리합니다.

### 1.1 계정 및 인증

- 필수: 이메일 주소, 비밀번호 해시, 닉네임, 사용자 식별자, 가입일, 로그인 방식, 인증 토큰
- Google 로그인 사용 시: Google 계정 식별자, Google ID 토큰 검증 결과, 이메일 주소
- Apple 로그인 사용 시: Apple 계정 식별자, Apple ID 토큰 검증 결과, 이메일 주소
- 이메일 인증 사용 시: 인증 코드 발송 및 검증 기록, 인증 시각
- 목적: 회원 식별, 로그인, 계정 보호, 세션 유지, 고객지원, 부정 이용 방지

알람톡은 비밀번호 원문을 저장하지 않습니다.

### 1.2 알람 설정 및 사용 기록

- 필수: 알람 시간, 반복 요일, 활성 여부, 스누즈 시간, 진동 설정, 알람 재생 모드, 알람음/음성 선택 정보, 다음 울림 예정 시각
- 선택: 알람 제목, 가족/파트너가 보낸 알람 여부, 알람 완료/스누즈/해제 이벤트, 연속 기상 기록, 캐릭터 성장 기록
- 목적: 알람 생성, 수정, 삭제, 동기화, 복원, 가족 알람 전달, 기상 기록 및 캐릭터 기능 제공

알람이 실제로 울리는 순간에는 기기 안의 로컬 데이터와 로컬 음성 파일을 사용합니다. 서버 장애나 네트워크 연결 여부는 핵심 알람 울림 경로의 필수 조건이 아닙니다.

### 1.3 음성 녹음, 파일 업로드, AI 음성 생성

- 사용자가 직접 제공하는 정보: 직접 녹음한 음성, 선택 또는 업로드한 오디오 파일, 잘라낸 음성 구간, 파일 형식, 파일 길이, 음성 프로필 이름
- AI 기능 사용 시: 음성 프로필 식별자, 화자 분리 결과, 음성 클론 제공자 식별자, TTS 입력 문구, 생성된 음성 파일, 생성 메시지 식별자, 생성 캐시 키
- 공유 설정 사용 시: 음성 공유 여부, 공유 대상 그룹, 공유 또는 수신된 음성 식별자
- 목적: 알람용 음성 등록, 음성 프로필 생성, TTS 알람 문구 생성, 로컬 알람 재생을 위한 캐싱, 가족/파트너 그룹 내 공유

음성 데이터에는 개인의 목소리 특성이 포함될 수 있으므로 알람톡은 이를 민감도가 높은 정보로 취급합니다. 회사는 음성 데이터를 사용자 본인 확인이나 인증 목적의 생체인식정보로 사용하지 않으며, 광고 타게팅이나 데이터 판매 목적으로 사용하지 않습니다. 음성 클론 및 TTS 생성은 음성 AI 제공자(제5조의 Perso, 운영사 이스트소프트)를 통해 처리되며, 해당 제공자는 자사 정책에 따라 이용자가 입력한 데이터(음성 포함)를 서비스 품질 개선 및 AI 모델 학습에 이용할 수 있습니다. 이용자는 AI 학습 목적의 이용을 거부할 수 있으나, 거부 시 음성 클론·TTS 등 일부 기능 이용이 제한될 수 있습니다(제6조 참고).

### 1.4 지역 및 동적 문구 설정

- 사용자가 직접 선택·입력한 경우: 국가, 도시, 날씨/운세 문구 설정값
- 목적: 사용자가 요청한 날씨 기반 알람 문구, 지역 기반 동적 문구, 설정 저장

알람톡은 단말기 GPS나 통신망 기반 위치를 자동으로 수집하지 않습니다. 지역 정보는 사용자가 국가와 도시를 직접 선택한 값만 처리하며, 이는 「위치정보의 보호 및 이용 등에 관한 법률」상 개인위치정보에 해당하지 않습니다.

### 1.5 가족/파트너 공유

- 필수: 초대 코드, 초대 상태, 그룹 식별자, 그룹 구성원 식별자, 공유 음성 식별자, 받은 알람/메시지 기록
- 목적: 가족/파트너 그룹 생성, 초대 수락, 그룹 내 음성 공유, 상대방 알람 설정, 받은 메시지 재생

알람톡은 음성 데이터를 공개 검색, 그룹 밖 공개 공유, 외부 다운로드 목적으로 제공하지 않습니다.

### 1.6 결제 및 이용권

- 결제 기능 사용 시: 요금제, 구독 상태, 상품 식별자, 결제 제공자, 결제/해지/갱신 상태, 이용권 또는 쿠폰 사용 기록
- 목적: 유료 기능 제공, 이용권 관리, 환불/해지 처리, 부정 이용 방지

알람톡 서버는 카드번호, 계좌번호 등 결제수단 전체 정보를 저장하지 않습니다. Google Play 결제 또는 Apple App Store 결제를 사용하는 경우 결제 처리는 각 앱 마켓 또는 결제 제공자의 정책에 따릅니다.

### 1.7 고객지원, 보안, 오류 분석

- 필수 또는 자동 수집: 문의 내용, 답변 이메일, 요청 시각, 접속 IP, User-Agent, API 요청 경로, 오류 코드, 기기 OS, 앱 버전, 빌드 버전, 오류 로그, 보안 이벤트
- 선택: 사용자가 첨부한 스크린샷, 로그, 재현 설명
- 목적: 고객 문의 처리, 장애 분석, 보안 사고 대응, 부정 이용 방지, 서비스 안정성 개선

오류 분석 도구에는 오류 원인 파악에 필요한 최소한의 진단 정보만 전송되도록 설정하며, 비밀번호 원문, 결제수단 전체 정보, 주민등록번호 등 고유식별정보를 수집하지 않습니다.

## 2. 개인정보 처리 목적

알람톡은 다음 목적을 위해 개인정보를 처리합니다.

- 회원 가입, 로그인, 계정 보호, 본인 확인
- OS 네이티브 알람 설정, 동기화, 복원, 로컬 재생
- 음성 녹음, 업로드, 화자 분리, 음성 프로필 생성, TTS 생성
- 가족/파트너 초대, 그룹 내 음성 공유, 상대방 알람 설정
- 날씨 등 사용자가 켠 동적 문구 기능 제공
- 캐릭터 성장, 기상 연속 기록, 이용권 제한 적용
- 결제, 구독, 이용권, 환불, 해지 처리
- 고객지원, 공지, 약관 및 정책 변경 안내
- 장애 분석, 보안, 부정 이용 방지, 법령상 의무 이행

회사(베일런)는 이용자의 음성 녹음, 업로드 파일, 생성 음성을 회사가 직접 운영하는 별도의 범용 AI 모델 학습에 사용하지 않습니다. 다만 음성 클론·TTS 기능 제공을 위해 음성 AI 제공자(Perso)에게 처리를 위탁하며, 해당 제공자는 자사 정책에 따라 입력 데이터를 자사 서비스 개선 및 AI 모델 학습에 이용할 수 있습니다(제5조·제6조).

## 4. 개인정보의 제3자 제공

알람톡은 이용자의 개인정보를 판매하지 않으며, 본 처리방침에 명시한 목적 범위를 넘어 제3자에게 제공하지 않습니다. 다만 다음의 경우에는 관련 법령에 따라 제공될 수 있습니다.

- 이용자가 사전에 동의한 경우
- 법령에 근거가 있거나 법원, 수사기관, 감독기관의 적법한 요청이 있는 경우
- 생명, 신체, 재산상 급박한 위험을 방지하기 위해 필요한 경우

가족/파트너 그룹에서 이용자가 음성 공유를 켜면, 그룹 구성원은 해당 음성을 알람 설정에 사용할 수 있습니다. 이 공유는 이용자가 선택한 그룹 안에서만 이루어지며, 언제든지 공유를 해제할 수 있습니다.
