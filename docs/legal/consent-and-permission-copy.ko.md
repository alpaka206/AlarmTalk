# 앱 내 동의 및 권한 문구

이 문서는 Android 앱 화면에 넣을 동의 문구 초안입니다. 스토어 심사에서 문제가 되기 쉬운 음성, 마이크, 파일, 알람 권한은 권한 요청 전에 먼저 설명해야 합니다.

## 1. 회원가입 필수 동의

제목: 서비스 이용을 시작하기 전에 확인해 주세요

본문:
알람톡은 알람 설정, 계정 동기화, 음성 알람 생성, 가족/파트너 공유 기능을 제공하기 위해 필요한 정보를 처리합니다. 자세한 내용은 개인정보 처리방침과 이용약관에서 확인할 수 있습니다.

체크박스:
- [필수] 만 14세 이상입니다. (서버 동의 유형: `age14`)
- [필수] 이용약관에 동의합니다. (서버 동의 유형: `terms`)
- [필수] 개인정보 처리방침을 확인했고 필수 개인정보 처리에 동의합니다. (서버 동의 유형: `privacy`)
- [선택] 이벤트, 업데이트, 혜택 안내 등 마케팅 정보 수신에 동의합니다. (서버 동의 유형: `marketing`)

버튼:
- 동의하고 시작하기

음성 생체정보(`voice_biometric`)와 국외 이전(`overseas_transfer`) 동의는 이 화면에서 받지 않습니다. 목소리를 등록하는 시점에 §2 화면으로 별도로 받습니다.

> 구현 메모: 가입 동의 게이트는 서버가 강제하는 일반 필수 동의(`GENERAL_REQUIRED_CONSENTS` = `age14`/`terms`/`privacy`)와 선택 동의(`marketing`)만 노출합니다. 민감 동의(`SENSITIVE_REQUIRED_CONSENTS` = `voice_biometric`/`overseas_transfer`)는 가입 조건이 아니며, 음성·TTS 경로에서 미동의 시 403(CONSENT_REQUIRED)으로 차단하는 방식으로만 강제됩니다(§2).
>
> 클라이언트는 **화면에 실제로 띄운 유형만** 제출합니다. 띄우지 않은 유형까지 함께 덮어쓰면 기존 동의(특히 마케팅)가 조용히 꺼지므로, 미노출 유형의 기존 기록은 그대로 두어야 합니다. 동의는 (유형, 정책 버전, 동의 여부, 시각)으로 누적 기록합니다.
>
> 처리방침/약관이 개정되어 정책 버전이 올라가도, 재동의는 그 개정으로 동의 내용이 실제로 달라진 유형에만 요구합니다(`CONSENT_MIN_POLICY_VERSION`).

## 1-A. 운세 · 동적 문구 기능 고지 (국외 이전)

제목: 운세 문구를 만들려면 생년월일 정보가 필요해요

본문:
운세 기반 알람 문구를 켜면, 입력하신 성별·생년월일·출생 시각이 알람 문구를 만들기 위한 내부 입력으로 사용됩니다. 동적(랜덤) 문구나 다국어 번역을 사용할 때는 알람 문구와 이 운세 정보가 Google Cloud Vertex AI(Gemini, 미국)로 전송되어 처리됩니다. 생성된 문구에는 생년월일·출생 시각 같은 원본 값이 그대로 노출되지 않습니다. 운세·동적 문구를 사용하지 않으면 이 전송은 발생하지 않습니다.

체크박스:
- [필수] 동적 문구·번역·운세 기능 사용 시 알람 문구와 운세 입력값이 국외(미국, Google Vertex)로 이전·처리되는 것에 동의합니다. (서버 동의 유형: `overseas_transfer`)

버튼:
- 동의하고 사용하기
- 취소

## 2. 음성 등록 전 별도 동의

제목: 알람 음성을 만들기 전에 동의가 필요해요

본문:
알람톡은 사용자가 녹음하거나 업로드한 음성을 분석하여 알람용 음성 프로필을 만들고, 선택한 문구를 해당 목소리로 생성합니다. 목소리는 개인을 식별·재현할 수 있어 **민감정보이자 생체정보**로 분류하며, 음성 클론(목소리 등록)은 아래 음성 생체정보 처리에 대한 별도 동의가 있어야만 진행됩니다(동의 없으면 서버가 차단).

필수 고지:
- 내 목소리 또는 동의를 받은 사람의 목소리만 등록할 수 있습니다.
- 권한 없는 타인의 목소리, 녹음물, 저작물, 대본, 음악을 등록하거나 AI 음성 생성에 사용할 수 없습니다.
- 등록한 음성, 녹음물, 문구의 권리는 본인 또는 원 권리자에게 있으며, 무단 등록으로 생기는 분쟁과 책임은 등록한 이용자에게 있습니다.
- 생성 음성을 사칭, 사기, 협박, 괴롭힘, 명예훼손, 불법 행위에 사용할 수 없습니다.
- 음성 파일은 음성 프로필 생성, TTS 생성, 알람 재생, 로컬 캐싱에 사용됩니다.
- 음성 생성 과정에서 Cloudflare, Turso/libSQL, ElevenLabs 등 외부 처리자가 데이터를 처리할 수 있습니다.
- 음성 클론·TTS는 음성 AI 제공자 ElevenLabs를 통해 처리되며, ElevenLabs는 실제 적용 계약과 정책에 따라 서비스 제공, 보안, 품질 관리, 장애 대응에 필요한 범위에서 데이터를 처리할 수 있습니다.
- 알람톡(베일런)은 음성을 공개 검색, 광고 타게팅, 데이터 판매 목적으로 사용하지 않으며, 베일런이 직접 운영하는 별도의 범용 AI 모델 학습에 사용하지 않습니다.
- 음성 프로필은 언제든지 삭제할 수 있습니다.

체크박스:
- [필수] 본인 또는 권한과 동의를 받은 사람의 음성만 등록합니다.
- [필수] 무단 음성 등록, 저작권/인격권 침해, 사칭 등으로 발생하는 책임이 등록한 이용자에게 있음을 확인합니다.
- [필수] 내 음성(생체정보)을 음성 프로필 생성·클론·TTS 생성에 사용하는 것에 동의합니다. (서버 동의 유형: `voice_biometric`)
- [필수] 음성 AI 처리를 위해 내 음성·문구가 국외(미국 등)로 이전·처리되는 것에 동의합니다. (서버 동의 유형: `overseas_transfer`)

버튼:
- 동의하고 음성 만들기
- 취소

> 구현 메모: 원본 음성 업로드, 음성 클론, TTS 생성 등 서버 음성 처리 경로는 필요한 민감 동의(`voice_biometric`, `overseas_transfer`)가 없으면 403(CONSENT_REQUIRED)으로 차단합니다. 국외 이전(`overseas_transfer`)은 음성 AI 처리(ElevenLabs) 및 동적 문구/번역(Google Vertex, 미국)이 데이터를 국외로 보내는 경로에서 요구되는 별도 동의입니다.

## 5. 정확한 알람 권한 안내

제목: 정해진 시간에 울리려면 정확한 알람 권한이 필요해요

본문:
알람톡은 푸시 알림이 아니라 Android의 OS 알람 기능으로 알람을 예약합니다. 정확한 알람 권한을 허용해야 화면이 꺼져 있거나 절전 상태여도 예약한 시간에 더 안정적으로 울릴 수 있습니다.

버튼:
- 설정으로 이동
- 나중에

## 6. 알림 권한 안내

제목: 알람 상태를 표시하기 위해 알림 권한이 필요해요

본문:
알람이 울리는 동안 상태를 표시하고, 백그라운드 재생을 안정적으로 유지하기 위해 알림 권한을 사용합니다. 광고성 알림은 별도 동의 없이 보내지 않습니다.

버튼:
- 알림 권한 허용
- 나중에

## 9. 가족/파트너 음성 공유 동의

본문:
공유를 켜면 가족/파트너 그룹 구성원이 이 목소리를 알람에 사용할 수 있습니다. 그룹 밖 공개나 외부 다운로드는 제공하지 않습니다. 언제든지 공유를 끌 수 있습니다.

체크박스:

- [필수] 이 음성을 그룹 구성원이 알람 설정에 사용하는 것에 동의합니다.

버튼:
- 공유 켜기
- 취소

## 11. 음성 프로필 삭제 확인

제목: 알람 음성을 삭제할까요?

본문:
삭제하면 이 음성을 새 알람에 사용할 수 없습니다. 이미 기기에 저장된 알람 음성 파일은 해당 알람을 삭제하거나 앱 데이터를 삭제할 때까지 남아 있을 수 있습니다.

버튼:

- 취소

## 14. 스토어 심사 노트용 설명

AlarmTalk is a native alarm app. The alarm ring path uses Android AlarmManager and local audio files. Push notifications, server cron, or live network access are not required at ring time. Voice recording/upload and AI voice generation are initiated only by explicit user action. Voice data is used for alarm voice profiles, TTS generation, local caching, and family/partner sharing inside the user's group. External public sharing or download is not provided.
